## 为什么选这六门课

首页 Demo 需要同时覆盖抽象推理、实验、工程实践与表达，且要能在 90 秒内讲清楚“课程是阵容、建议有依据、失败可降级”。本轮从已经完成 L3 审核的本地课程索引中选出：

| Demo 课程 | 索引证据 | 可公开复用的摘要 | V0.9 用途 |
|---|---|---|---|
| 信号与线性系统 | 6 个历史 Office 原件（5 DOCX + 1 PPTX）；65/65 页或幻灯片只读核验；RC/RLC、傅里叶、频率响应、采样、MATLAB/Multisim | 课程名、主题标签、风险边界与建议输出类型 | 首页首发主课；RC/RLC → Bode → 误差解释 |
| 光学 | 19 个索引文件；几何光学、干涉、衍射、偏振 | 课程名与主题标签 | 观察—模型—证据的课程卡 |
| 电子电路 | 48 个索引文件；器件、模拟/数字电路、测量与安全 | 课程名与主题标签 | 设计、测量与安全的课程卡 |
| 高等数学 | 180 个索引文件；极限、微积分、级数、多元函数、常微分方程 | 课程名与主题标签 | 抽象定义—可视化—严格条件的课程卡 |
| 学术英语 | 3 个课程导出包；303 条 HTML、DOCX、PPTX、PDF 结构化提取；学术读写、论证、引用与修订 | 课程名、主题标签与通用写作方法 | 主张—证据—限制的表达课程卡 |
| 工程训练 | 174 个索引文件；安全、制造、测量、3D 打印、机器人、CNC | 课程名与主题标签 | 安全—制造—验收的实践课程卡 |

这里的数量只描述已审核目录摘要或只读核验记录，不表示把这些文件打包进产品，也不能反推出学生身份或成绩。`demoSeason.ts` 中的课程问题、三段分析路径、Next Move、代码、赛季与进度全部是可替换 Fixture；只有课程名、主题和证据边界来自摘要层事实。

## 权威级别

- `sourceRef` 只证明该课程名和主题摘要来自已审核索引，例如 `course-index:signal-linear-systems:2026-07-22`。
- `authority=fixture` 表示首页人物、日期、课程代码、进度、等级、里程碑和 Next Move 都是虚构演示数据。
- V0.9 不连接 SIS / URP / LMS，不写入教务、选课、消费、门禁或学籍系统。
- 任何未来真实数据必须经过 Academic Mirror 的来源、版本、授权、权威级别和撤回流程。

## 明确不进入公开仓库

- 原始 PPT、PDF、Word、音视频、作业、题库和考试内容；
- 姓名、学号、班级、邮箱、真实课表、成绩、排名和出勤；
- 能识别学校、教师或同学的内部链接与访问凭据；
- 未确认许可的第三方教材、图片、音频和课程平台内容。

## AI 接手检查

新 AI 修改 Demo 课程时必须同时确认：

1. 课程仍存在于已审核索引，且只使用摘要层事实；
2. 新字段能被清楚区分为 `source summary` 或 `fixture`；
3. UI 的“依据”抽屉仍能解释来源、更新时间、后端状态和非权威边界；
4. `npm run verify --prefix app/apps/web` 与仓库根验证通过；
5. 任何真实数据接入都另开任务，不在 Demo Fixture 中偷渡。
