# jiaowu2K26 愿景

## 愿景声明

> jiaowu2K26 把大学四到八年的学习、选课、成长与协作重构成 MyCareer 式大学生涯：学期是赛季、课程是阵容、每一次选择都有依据、每一次进步都能回放。它从首个 P0 模块「智课工坊」起步，让 AI 先亮出来源、由教师审核后再发布，逐步把冷冰冰的办事大厅升级成可信、可玩、真正让人想打开的大学生活体验层。

## 项目身份

- **总项目：** jiaowu2K26
- **起点与首个 P0：** 智课工坊 / SmartCourse Studio
- **系统定位：** SIS / URP / LMS、校园卡、财务、门禁、科研与人事等权威系统之上的大学生涯决策与体验层——不替换权威系统，而在其上提供授权镜像、解释、规划、学习、反馈、模拟与叙事
- **设计借鉴：** NBA 2K 赛季 / 阵容 / 训练 / Replay / 管理模拟语法（借机制不借品牌）
- **赛事：** AdventureX 2026，72 小时现场黑客松

## 长期产品范围：一个大学世界，三种角色 Lens

| 角色 Lens | 游戏化身份 | 解决的问题 | 主要模块 |
|---|---|---|---|
| 学生 | MyCareer | 从入学、课程、选课、考试、消费、通行、饮食、科研、机会到毕业/校友的连续生涯 | F-001～F-006、F-008～F-012 |
| 教师 | Coach Studio | 教学设计、课程反馈、科研机会、合规、协作、证据档案与晋升准备 | F-001、F-007、F-009、F-013 |
| 学校 | Front Office | 招生、学籍、排课、学生支持、财务、空间、餐饮、科研、教师发展与政策 What-if | F-003、F-004、F-010～F-014 |

三种 Lens 共用同一身份与授权框架、证据链、设计系统和事件语法。它们不是三套拼接产品：角色只改变权限、信息密度和主任务，不改变美术语言、导航逻辑或“Briefing → Choose → Execute → Replay → Next Move”的核心循环。

新增长期模块已收进 [University OS 扩展包](../modules/09-university-os/SPEC.md)：

- F-010 Campus Pass & Entitlements：门禁、实验室、设备与非货币权益
- F-011 General Balance & Campus Commerce：通用余额、政策补助、外部支付通道与 Module Cap
- F-012 Dining & Wellbeing：菜单、预算内食谱、过敏原、排队与食堂运营优化
- F-013 Faculty Success Studio：教师教学、科研、合规与晋升证据
- F-014 Institutional Front Office：全校服务、资源、数据与政策模拟

这些能力是**已经纳入产品范围的可选路线图**，不是本届必须完成清单。任何时候都允许不做；只有核心闭环稳定、团队有人负责且有明确现场证据时，才启动一个最小 Slice。

## MVP 范围

### P0 必须完成

P0 的唯一闭环：

```
F-002 轻量赛季入口 → F-001 来源登记 → AI 草稿生成 → 教师审核（修改/通过/移除）→ 仅发布已通过对象 → 学生互动 → Replay / Box Score
```

- F-001 智课工坊：完整纵向切片——来源片段、草稿合同、结构校验、教师审核队列、发布门禁、学生互动、Replay
- F-002 MyCareer 赛季中心：P0 轻外壳——当前赛季首页、课程阵容（F002-03/F002-04）
- F-003 Academic Mirror：P0 使用授权样例或 `demo_fixture` 替代真实镜像

  > 注：P0 阶段仅使用 `demo_fixture` 替代数据，模块本身的完整开发归入 P1。

- 共享能力 X-02（来源与证据）、X-03（事件与审计）、X-08（可访问性）、X-09（离线与降级）必须进入真实路径
- EXP-CASE-01 Human Override 和 EXP-CASE-02 Evidence Pack 只作为上述共享能力的验收别名：不增加 P0 页面或支线，但要求 AI 结果可纠正、关键事件可回放

### P0 明确不做

- 学籍主库、财务、正式成绩写回
- 全校排课（机构级 F-004）
- 生产级身份治理、完整登录/注册/权限系统
- 真实招聘自动投递、真实支付/校园余额、门禁签发或门锁控制
- 完整 3D 校园、Unity/Unreal 客户端
- 自研动画引擎
- 真实学校教务系统对接（仅用授权样例或手工导入）
- 多学科泛化、真正的个性化推荐算法

### P1 候选（P0 稳定后最多选一个）

| 候选 | 选择理由 | 6–12h 可行性 |
|------|---------|-------------|
| F-003 Academic Mirror 小样 | 与 P0 集成最紧，用 fixture 升级授权数据 | 高 |
| F-004 Roster Lab 个人版 | 技术辨识度最高（Conda 式 diff） | 中，求解器有风险 |
| F-005 World Exam Finals Replay | Demo 效果最好，复用 F-001 来源链 | 高 |
| F-009 Opportunity Market 透明资格匹配 | 独立性最强，不依赖 P0 内部状态 | 中 |

选择标准：直接增强主题/赛道证据、数据有权使用、主闭环不受影响、失败有回退。**不得同时开四条支线。**

## 成功标准

- [ ] P0 闭环可完整演示：来源 → 审核 → 发布 → 互动 → Replay
- [ ] 至少 3 位教师用户完成测试反馈（记录任务完成、审核时间、编辑类型、误解与失败）
- [ ] 所有 AI 生成内容有可定位来源（`source_id` 可回看原文页码/时间戳/文本跨度）
- [ ] 只有 `approved` 版本可发布，未通过对象绝不进入学生端
- [ ] 90 秒 Demo 可流畅走通（赛季入口 → 草稿与来源 → 教师审核 → 发布 → 学生互动 → Replay/Box Score）
- [ ] 模型不可用时，规则/fixture 回退仍可诚实演示审核状态机
- [ ] 对外说法不超过现场证据，无结果性声称

## 36 小时停损线

如果智课工坊主闭环在正式开赛后第 36 小时仍不稳定：

- **冻结** 所有 P1（F-003 / F-004 / F-005 / F-009）
- **冻结** 硬件集成（D-Robotics / Tuya）
- **冻结** WinUI 3、Unity、Unreal 客户端
- **冻结** 所有视觉扩展（3D 校园、高级动效）
- **全力修复** 来源、审核、发布和学生互动的完整闭环

## 角色分工预期

| 能力岗 | 核心职责 | 缺省时合并方式 |
|------|---------|--------------|
| 产品 / 总集成 | 产品定义、用户测试、赛道选择、停损、跨模块验收与 Claim Ledger | 由队长兼任，可兼视觉/宣发 |
| 前端 / 交互 | UI、交互、可访问性、空/失败/回退状态 | 不与 P0 后端 owner 同时空缺 |
| 后端 / 证据链 | API、状态机、数据库、来源、发布门禁与审计 | 可兼部署和自动化测试 |
| AI Pipeline / 评测 | 材料解析、结构化生成、来源约束、Schema、模型回退与评测 | 人数不足时并入后端，但保留独立验收 |
| 视觉 / 人因 / 宣发 | 招募、海报、90 秒 Demo、理解测试和路演 | 人数不足时并入产品 |

> 能力岗不等于人数。四人建议“产品总集成 / 前端 / 后端 / AI Pipeline”；视觉宣发由产品主责、全员协作。三人合并后端+AI；两人只做 P0，砍掉 P1、硬件和多客户端。

## 产品原则（摘要）

1. **体验层不冒充权威层**——镜像、预测和 What-if 必须显式标注
2. **AI 必须 Show your work**——能回到来源、规则、版本和人的决定
3. **人保留决定权**——教师决定发布，学生决定披露，学校决定正式资格
4. **2K 是产品语法**——借鉴赛季、阵容、训练、回放和管理循环，不复制品牌与画面
5. **小闭环先于功能展柜**——P0 只证明「来源 → 审核 → 发布 → 互动 → 回放」
6. **每项能力可回退**——网络、模型、数据库或硬件失效时仍可诚实演示核心价值
7. **一个世界而非模块拼盘**——所有角色和模块强制复用同一游戏化外壳、Token、组件、图标、动效和叙事语法
8. **统一不等于强迫沉浸**——沉浸、轻量、传统和减少动效模式共享同一信息架构与完成度，用户可降噪但不会掉进粗糙后台
9. **真实权益不做游戏货币**——General Balance、政策资金、外部支付通道、Module Cap 和非货币 Entitlement 分层呈现，绝不付费买成绩、资格或优先级
10. **Windows 先验不等于 Windows 锁定**——第一版优先在 Windows 验证，但领域合同、状态、数据和 Design System 必须可迁移到 macOS、iOS、iPadOS、Android 与 HarmonyOS 7
11. **学校保有数据主权，学生保有个人副本**——学校决定正式记录的权威边界；学生可取得可读非权威归档与发行方签名、可选加密、受控导入的可信归档
