## 1. 90 秒 Demo 脚本

### 核心闭环

```
赛季入口 → 一门课程 → AI 草稿与来源 → 教师审核 → 发布 → 学生互动 → Replay / Box Score
```

### 逐秒脚本（含话术）

| 时间 | 操作 | 话术 | 证明 |
|---:|---|---|---|
| 0–10s | 打开 MyCareer 赛季首页，进入《数据结构》课程 | "大学体验不该只剩办事大厅。jiaowu2K26 把学期变成赛季，课程变成阵容。" | 总项目愿景入口 |
| 10–25s | 打开一个 AI 草稿，点击"查看证据"侧栏，展示来源片段（PPT 第 3 页 + 口播 03:45） | "智课工坊的核心规则：AI 必须先 Show your work。每个生成片段都能回到来源——PPT 哪一页、录音哪一秒。" | 可定位来源链 |
| 25–45s | 教师修改一处脚本 → 通过一个对象 → 移除一个对象 | "教师保留决定权。修改保存差异，通过记录审计，移除保留原因。未通过的对象绝不会到学生端。" | 审核状态机 + 追加式审计 |
| 45–55s | 点击"发布"，系统提示只有已通过对象被包含 | "发布门禁：只有 approved 版本能发布，来源仍有效才能发布。学生端立刻可见。" | 发布门禁成立 |
| 55–75s | 切换到学生视角：播放学习内容 → 弹出测验题 → 学生作答 → 显示解析和来源 Badge | "学生完成理解检查。每道题可以查看教师批准的解析，还能看到来源——这道题来自老师的口播重点。" | 可操作产品 + 学生互动 |
| 75–88s | 打开 Replay 时间线和 Box Score | "每个结果能回到来源和修改记录。完成率、正确率、用时分布——学生看到自己的成长，教师看到教学效果。" | 证据闭环 |
| 88–90s | 回到赛季首页 | "Show your work. For AI. In education." | 记忆点 |

### 演示要点

- 全程**真实操作**，不用预录视频（除非触发 Fallback）；
- 预加载已生成的草稿数据，跳过 AI 生成等待时间；
- 教师审核和学生互动在**同一浏览器**内切换标签页完成；
- 审核事件的追加式日志可以在侧栏实时看到。

## 1.1 唯一 Magic Moment

路演不展示一排“我们还能做什么”，而展示一次不可逆的理解变化：

> 一份普通课程材料进入系统，AI 必须亮出来源；教师当场修改并批准；学生只看到批准版本；最后一个 Replay 把来源、人的决定和学习结果重新连起来。

Magic Moment 同时满足：

- 评委在 20 秒内看见“原材料 → 可审核对象”的前后差异；
- 教师修改不是装饰按钮，发布门禁会真实拒绝未批准对象；
- 学生端与教师端消费同一对象版本，不准备两套假数据；
- Replay 使用稳定 Evidence Pack，至少展示事件 ID、来源、操作者、前后状态和时间；
- 演示结束后，第一次听到项目的人能复述“AI 先举证、老师再决定、学生最后回放”；
- 不为证明愿景而跳转 General Balance、门禁、排课、3D 校园或其他未实现页面。

### Magic Moment 证据包

现场冻结以下材料并登记时间/版本：授权输入、来源片段、模型/规则信封、教师修改 diff、发布版本、学生作答、Replay 事件、一次失败/回退记录和完整录屏。任何一项缺失，相应能力不得在路演中称为完成。

## 2. Fallback 四级保底

| 级别 | 触发条件 | 现场行为 | 对评委的说法 |
|---|---|---|---|
| **L1: 模型不可用** | AI 模型超时/额度耗尽 | 加载 `demo-pack` fixture 草稿，继续真实审核状态机 | "模型不可用，当前是预置输入；审核和发布仍实时运行" |
| **L2: 数据库不可用** | OceanBase 连接失败 | 切同 repository 合同的 SQLite | "主库连接失败，使用本地事务回退，数据合同不变" |
| **L3: 无网络** | 现场 WiFi/热点全断 | PWA + 本地服务 + 已授权缓存；禁用外链动作 | "当前离线，来源快照时间为……" |
| **L4: 服务全崩** | 后端完全不可启动 | 纯前端 + JSONL fixture / 录屏 + 截图 + 口头讲解 | "后端不可用，用预置数据演示前端交互；架构设计和状态机仍然成立" |

### Fallback 纪律

- 每次切换 Fallback 必须**口头声明**当前级别，不伪装实时成功；
- fixture 数据明确标注 `generation_mode: "fixture"`，不与真实结果共用状态标签；
- L1–L3 的审核状态机仍然真实运行，只有输入源不同；
- 路演前至少完整演练 L1 和 L4 各一遍。

## 3. Must-Show / Must-Hide

### Must-Show（必须展示）

| 优先级 | 展示内容 | 展示方式 | 目的 |
|---|---|---|---|
| P0 | 来源片段与 AI 草稿同屏并置 | 现场操作 | 证明"AI Show your work" |
| P0 | 教师审核（edit / approve / remove） | 现场操作 | 证明人保留决定权 |
| P0 | 发布门禁（只有 approved 可发布） | 现场操作 | 证明状态机约束 |
| P0 | 学生完成理解检查 + 查看来源 Badge | 现场操作 | 证明闭环互动 |
| P0 | Replay 时间线 + Box Score | 现场操作 | 证明证据可回溯 |
| P1 | fixture 回退仍走真实状态机 | 口头说明 + 快速演示 | 证明可降级但不造假 |
| P2 | 追加式审计日志 | 侧栏展示 | 技术辨识度 |

### Must-Hide（不得展示）

| 不展示内容 | 原因 |
|---|---|
| AI 生成等待时间（30–60s） | 破坏演示节奏 |
| ASR 转写中间过程的错别字 | 影响"AI 可用"感知 |
| 后台管理界面和数据库操作 | 评委不关心实现细节 |
| 未完成的实验性功能 | 暴露不稳定性 |
| API 调用日志和错误堆栈 | 技术噪音，分散注意力 |
| 其他学生的敏感数据 | 隐私合规 |
| 密钥、Token、第三方凭证 | 安全红线 |

## 4. Pitch 结构

### 30 秒版（电梯演讲）

> 1. 大学教师有材料、没时间做互动课；学生有网课、没理由看得下去；
> 2. 智课工坊让 AI 从教师材料中提取来源、生成草稿，教师审核后发布，学生完成互动并回放证据；
> 3. 本届只先证明这一条闭环：来源 → 审核 → 发布 → 互动 → 回放；
> 4. 展示现场真实运行和一个测量限制。

### 2–3 分钟 Expo 版

| 段落 | 时间 | 内容 |
|---|---|---|
| 问题/愿景 | 15s | "教师已经有讲义、课件和录课，却缺少把它们快速变成可审核互动内容的时间；学生也很难从长材料里定位重点、依据和下一步。" |
| 真实操作 | 90s | 走 90 秒 Demo 脚本 |
| 技术难点 | 20s | "来源合同让 AI 不能编造证据；审核状态机让未通过内容绝不发布；每条回退路径可诚实降级。" |
| 实测与局限 | 20s | "用 BST 课程实测：X 个来源片段、Y 个生成对象、Z 位教师审核。脚本可用率约 N%（如有数据）。限制：单学科、小样本、不代表学习效果。" |
| 路线图 | 15s | "P0 证明闭环 → P1 扩展 Academic Mirror / Roster Lab / World Exam → 6 个月验证 20 门真实课程。" |

> **三种 Lens 展示预案：** 当前 90 秒脚本聚焦学生 MyCareer Lens（P0 闭环）。如果 P1 启动了 University OS 某个 Slice，Demo 可扩展为“同一信息架构，切换 Coach Studio 或 Front Office Lens”的演示，体现“一个世界、三种视角”。

### 记忆点（给评委留下的印象）

- **Show your work：** AI 是那个从不 Show your work 的学生；我们让它参加开卷考，并真正核对它翻过的书
- **教师保留决定权：** AI 生成，教师审核，学生互动——人不退出循环
- **可信降级：** 模型挂了、数据库断了、网络没了——审核状态机仍然真实运行
- **Conda 式学期 diff：** 让选课 What-if 像环境解析一样可解释（P1 Roster Lab）

## 5. Q&A 预案

### 技术类

**Q1: AI 生成质量不稳定怎么办？**
- A: 三层保障——来源约束生成（只能引用已提供片段）、结构校验（schema + 空内容检查）、教师审核（人最终决定）。模型失败时用 fixture 继续验证状态机。

**Q2: 为什么不直接用 RAG？**
- A: 先词法搜索 + 来源链接，有真实数据证明不够再升级向量。向量相似度 ≠ 证据支持度。不为"RAG"标签增加不可验证复杂度。

**Q3: Rust 选型理由？72 小时够吗？**
- A: Rust 适合表达审核状态机、不可变不变量和可替换适配器。6h 闸门验证纵向切片，未通过立即切团队最熟悉的后端。

**Q4: 数据安全怎么保证？**
- A: 课程材料需权利说明才能进入生成；学生数据最小化；密钥只放环境变量不提交；审核/发布事件只追加不可篡改。

### 产品类

**Q5: 教师会不会觉得 AI 脚本"不够专业"？**
- A: 这正是教师审核环节存在的意义——AI 起草 + 教师把关。教师痛点是"没时间从零做互动课"，不是"AI 写得不好"。

**Q6: 和洋葱学院/MOOC 有什么区别？**
- A: 我们不替代 MOOC、LMS 或现有内容平台。差异在于从教师有权使用的大学课程材料出发，把“可定位来源 → 教师审核 → 批准后发布 → 学生互动 → Replay”做成可验证闭环；对洋葱学院等产品只做工作流和内容节奏参考，不作覆盖范围的绝对判断。

**Q7: 数据飞轮冷启动怎么办？**
- A: 先做 10-20 个高质量 fixture 种子 → 找 1-2 个种子大学教师合作 → 学生答题数据从第一天积累。小飞轮先转，验证后再加速。

### 商业类

**Q8: 怎么获客？B2B 决策链很长。**
- A: 短期找"创新型教师"个人合作（教改课题经费可自主决策）；中期用效果数据走院系推荐；长期进采购目录。

**Q9: 这个方向验证失败怎么办？**
- A: 底层能力（材料→脚本→互动→回放）通用。可 Pivot 到企业培训、考研考证、K12 工具授权。

**Q10: API 成本上涨怎么办？**
- A: 后端按可替换 Provider Adapter 设计，并保留规则/fixture 回退。只有现场记录模型、输入输出 Token、调用次数、失败重试和价格快照后，才报告单课成本；赛前不写未经实测的金额。

### 合规类

**Q11: 课程材料版权怎么处理？**
- A: 上传不等于默认转让版权或获得再分发权。每份材料先登记权利状态、允许用途、发布范围、期限和撤回方式；黑客松优先使用团队自制或明确授权样例。生成物的归属、署名和分发须按实际协议、模型条款与适用法律另行确认，团队不在界面或口头承诺中擅自下结论。

**Q12: 2K 官方有授权吗？**
- A: 2K 是产品语法借鉴（赛季/阵容/回放），不是品牌或视觉复制。不使用 NBA 2K 截图、品牌或素材进入参赛产品。

## 6. Demo 准备清单

### 路演前必做

- [ ] 确认 Demo 课程（BST）的 fixture 数据完整加载
- [ ] 测试完整路径：上传 → 生成 → 审核 → 发布 → 互动 → Replay
- [ ] 测试 L1 Fallback：断网/模型超时后 fixture 模式仍可走审核状态机
- [ ] 测试 L4 Fallback：纯前端 + 截图/录屏可独立演示
- [ ] 标记所有 Demo 中需要"预加载"的数据点
- [ ] 准备手机热点作为备用网络
- [ ] 录制完整 Demo 视频（3 分钟以内）作为 L1 保底
- [ ] 准备 5-8 张关键截图插入 PPT 尾部作为 L4 保底

### 路演前 30 分钟

- [ ] 全员走一遍 Demo 流程，确认无 Bug
- [ ] 主演讲人过一遍脚本（不要背，要自然）
- [ ] 确认 Q&A 分工（谁主答哪类问题）
- [ ] 计时器放在视野内

### 路演中纪律

- [ ] 90 秒 Demo 严格计时，宁可少展示一个功能也不超时

- [ ] 用 ACE 框架回答 Q&A：Acknowledge → Core → Evidence
- [ ] 不确定的问题坦诚说"这是我们接下来要验证的"
- [ ] 对外说法不超过现场证据，不作结果性声称

## 7. 路演加分与避坑

### 加分项

| 行为 | 效果 |
|---|---|
| 现场展示来源并置——让评委亲眼看到 AI 草稿对应的 PPT 页码 | 眼见为实 |
| 主动提到 Fallback 并展示降级能力 | 展示工程成熟度 |
| 用"Show your work"做全场记忆点 | 一句话钉住产品核心 |
| 结束时留下具体 Ask（"寻找种子大学合作伙伴"） | 有行动力 |
| 准备架构图 Appendix 页 | Q&A 被问技术细节时翻出 |

### 避坑项

| 踩坑行为 | 替代方案 |
|---|---|
| 说"我们没有竞争对手" | 说"赛道空白，但有潜在进入者" |
| Demo 超时 | 严格计时，宁可少展示一个功能 |
| 堆技术术语 | 说"语音识别""来源追踪""审核状态机" |
| 展示未完成界面 | 只展示完成度最高的路径 |
| 路线图过于宏大 | 聚焦"6 个月验证 20 门真实课程" |
| 用小样本声称提升学习效果 | 只报告过程指标，不作结果性声称 |
