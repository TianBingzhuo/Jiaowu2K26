# Academic Mirror · 功能规格

> **功能 ID：** F-003 · **优先级：** P1 候选
> **基线日期：** 2026-07-21 · **状态：** Fixture 技术候选已实现，待产品总集成人员验收

> 当前实现证据、逐项结论与未完成边界见 [`STATUS.md`](STATUS.md)。所有来源、学生与记录均为脱敏 Fixture；六级权威分类用于验证合同，但有效权威级别统一为 `demo_fixture`，不代表已连接学校系统。

## 功能概述

在不冒充 SIS/URP/LMS 的前提下，把授权数据转为可追溯、可纠错、可被体验层安全读取的镜像。每个数据字段都带来源、版本、获取时间和权威等级。

## 核心不变量

1. **镜像不是权威记录：** Academic Mirror 不是正式选课、成绩、学籍、支付或审批结果；模拟和正式状态必须在视觉与数据上同时区分
2. **无来源不决策：** 无授权、无来源或过期严重的数据不能支持高风险决定（如选课、毕业判断）
3. **冲突不静默覆盖：** 同一事实多源冲突时必须列出差异，不能自动选择"最新"或"最权威"而忽略其他来源
4. **原始快照不可变：** RawSnapshot 一旦写入不可修改；后续同步产生新快照，旧快照保留用于审计
5. **字段级追溯：** 每个标准化字段独立追溯，不只在记录级标注来源
6. **同意是前提：** 无有效同意的数据不能被下游模块读取；扩大用途需重新同意
7. **P0/P1 不依赖真实数据：** 所有演示可用 demo_fixture 完成，不要求真实学校账号
8. **只读默认：** 默认无写回能力；任何写回需要独立授权和双重确认

## 权威等级定义

| 等级 | 含义 | 来源示例 | 可用于高风险决策 |
|------|------|----------|-----------------|
| `authoritative` | 学校官方权威记录 | SIS 正式成绩、学籍 | 是 |
| `official_reference` | 官方参考数据 | 课程目录、培养方案 | 是 |
| `authorized_mirror` | 授权镜像数据 | 授权 API 导出 | 需确认新鲜度 |
| `self_declared` | 本人声明 | 学生自报兴趣/目标 | 否 |
| `model_inferred` | 模型推断 | AI 分析结论 | 否 |
| `demo_fixture` | 演示夹具 | 虚构/样例数据 | 否 |

## 最小数据合同

```
source_system / external_id / source_version
fetched_at / effective_at / authority_level
raw_reference / normalized_payload
consent_basis / correction_route / expires_at
```

所有下游模块通过此合同读取数据，不需要直接访问原始系统。

| entity_type | 描述 | 关键来源系统 |
|-------------|------|-------------|

## API 合同补充

### 错误响应规范

```json
{
  "error": {
    "code": "SOURCE_UNAUTHORIZED | SYNC_FAILED | CONFLICT_UNRESOLVED | CONSENT_MISSING | RECORD_EXPIRED | PERMISSION_DENIED",
    "message": "string",
    "retryable": "boolean",
    "fallback_available": "boolean"
  }
}
```

### 新鲜度检查

下游模块请求数据时，系统自动检查 `expires_at`：
- 未过期：正常返回
- 接近过期（剩余 < 20% 有效期）：返回数据 + `freshness_warning`
- 已过期：返回数据 + `expired` 标记，高风险场景拒绝

## 安全与隐私要求

### 数据分级保护

| 数据类型 | 保护级别 | 可见范围 |
|----------|----------|----------|
| 成绩/GPA | 高 | 仅本人 + 授权教师 |
| 课程/学期 | 中 | 本人 + 相关教师 |
| 活动/科研 | 低 | 本人 + 同意模块 |
| 演示夹具 | 无 | 所有人 |

### 最小权限原则

- 下游模块只能读取学生已同意的数据范围
- 查询审计日志本身受权限保护（不能通过审计日志反推敏感数据）
- 导出操作记录数据范围和时间

### 纠错渠道

- 每条记录显示 `correction_route`（如何联系权威系统修正）
- 用户可申请修正非权威副本，但正式记录修正需联系原始系统
- 修正申请进入人工校对队列，不自动生效
