## 记录规则

1. 优先使用官方学校、厂商、项目上游仓库和官方文档；
2. 把“来源明确写了什么”和“本项目由此推断什么”分开；
3. 每份研究保存查看日期、直接链接、未知项和不能外推的边界；
4. 动态事实（版本、规则、价格、功能、权益）在实际采用前重新核对；
5. 研究对象不自动成为依赖，进入代码前仍须走版本、许可、安全和赛事闸门；
6. 若新证据改变产品方向，同步更新主题文档、[决策日志](../DECISIONS.md)、[机器清单](../PROJECT-MANIFEST.json) 和 [AI 交接](../AI-HANDOFF.md)。
