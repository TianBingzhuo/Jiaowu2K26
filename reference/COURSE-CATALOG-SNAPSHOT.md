## 与 V0.9 Demo 的关系

1. `subjectCatalog.ts` 保存上述发现入口、分类、别名来源组和 README 就绪状态，不保存本机目标路径。
2. `demoSeason.ts` 保存六门可公开演示的课程阵容和 Fixture 分析；课程名/主题/证据边界来自已审核摘要，问题、三段分析路径、代码、进度和 Next Move 是演示数据。
3. 一个发现入口只有在对应 README / 课程索引复核、隐私检查和证据引用完成后，才能晋升为 Demo 课程分析。
4. 发现池新增或删除入口时，必须重新只读盘点快捷方式并更新本快照、运行数据与测试；不得凭记忆手填“所有课程”。
