# 智课工坊现场 Demo 操作卡

**用途**：AdventureX 现场路演前最后 30 分钟使用  
**原则**：先演稳定闭环，再展示技术细节  
**Demo 主线**：BST 一节课，从老师材料到学生互动课

---

## 1. 演示前检查

| 检查项 | 通过标准 |
|--------|----------|
| Demo Mode | 能一键加载 `demo-pack/golden/` 数据。 |
| 教师审核页 | 能展示脚本、考试信号、证据按钮。 |
| 证据抽屉 | 至少能打开 2 个证据对象。 |
| 学生播放器 | 能推进到题目弹层。 |
| 题目弹层 | 能提交答案并显示解析。 |
| 复习卡 | 能展示 S 级重点和来源 badge。 |
| 断网兜底 | Golden 数据可本地读取。 |

---

## 2. 90 秒演示脚本

### 0-15 秒：问题进入

> 老师手里已经有 PPT、录播和讲义，但学生很难从 60 分钟内容里抓重点。智课工坊把这些沉睡课程资产转成短动画、即时题目和复习卡。

操作：打开教师审核页。

### 15-35 秒：教师审核

> 这里 AI 已经把二叉搜索树这一节拆成 5 个场景。老师不需要从空白开始，只要审核、修改、发布。

操作：点击场景 s2 的“查看证据”。

### 35-55 秒：证据模式

> 关键是每个 AI 输出都有证据链。比如“左小右大”这段，来自老师口播，也来自 PPT 第 2 页，所以老师知道它不是凭空生成。

操作：展示证据抽屉，停 5 秒。

### 55-75 秒：学生互动

> 学生端会看到更短的互动知识点，中途弹出一道和刚才内容直接相关的题。

操作：切到学生播放器，推进到 q1，提交正确答案。

### 75-90 秒：复习闭环

> 最后它会自动沉淀成复习卡，尤其是老师口头强调过的 S 级重点。这样老师的经验不会只停留在录播里。

操作：打开复习卡，指向“老师重点”badge。

## 3. 现场点击顺序

```text
1. 打开 /teacher/review
2. 点击“加载预生成结果”
3. 点击 s2 场景的“查看证据”
4. 点击“通过”
5. 点击“发布到学生端”
6. 打开 /student/watch/bst-001
7. 播放到第 95 秒题目
8. 选择“左子树”
9. 打开 /student/review/bst-001
```

## 4. Fallback 顺序

| 失败点 | 立刻切换 |
|--------|----------|
| ASR 失败 | 用 `demo-pack/source/bst_transcript.md`。 |
| PPT 解析失败 | 用 `demo-pack/source/bst_slide_extract.json`。 |
| LLM 等太久 | 用 `demo-pack/golden/script_bst.json`。 |
| 证据接口失败 | 打开 `demo-pack/fallback/screenshots/evidence_mode_mock.html`。 |
| 播放器失败 | 打开 `demo-pack/golden/player_data_bst.json` 解释数据结构，或播放录屏。 |
| 网络失败 | 全程 Demo Mode，读取本地 golden 数据。 |

## 5. 路演话术禁区

| 不建议说 | 建议替换 |
|----------|----------|
| 我们可以完全替代老师 | 我们帮助老师把已有内容转成互动学习单元。 |
| AI 自动生成后直接发布 | AI 生成后进入老师审核流。 |
| 可以适配所有课程 | 先从结构化强、知识点清晰的课程试点。 |
| 已经能大规模商业化 | 先用种子教师试点验证指标。 |
| 模型一定不会出错 | 证据链和审核流用来降低错误风险。 |

---

## 6. 演示结束后的收束句

> 智课工坊的核心不是又做了一个 AI 生成工具，而是把老师已有课程资产变成可审核、可互动、可复习的学习体验。我们这次先用一节数据结构课跑通最小闭环，后续可以扩展到更多课程。
