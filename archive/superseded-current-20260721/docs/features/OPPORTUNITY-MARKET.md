# F-009 · Opportunity Market（机会市场与权益系统）

> **状态：**P1/P2 产品候选，未实现。
> **前置条件：**智课工坊 P0 已稳定，现场主题/赛道与团队能力匹配，并且机会数据来源、同意和公平边界可说明。
> **一句话：**把 2K 的 VC、卡包、拍卖行、Pass 和 Transfer Portal，改造成透明、不可买分、由本人授权的大学机会发现与转段解释系统。

## 为什么它属于 jiaowu2K26

大学机会常散落在学院通知、公众号、群聊、实验室、会议网站、招聘平台和同学转发里。真正的门槛不只是“有没有机会”，而是学生很难同时判断：

- 它是否适合我，资格差在哪里？
- 截止时间、成本、地点和导师是谁？
- 需要哪些课程、作品、语言或时间投入？
- 我提供了哪些个人信息，谁能看到？
- 这是正式资格、推荐结果，还是系统推断？

机会市场不是把教育商品化，而是把分散信息、资格、资源取舍和双向匹配变得可解释。

## 五个机制的重新设计

| 2K 原机制 | 大学场景 | 可做的产品能力 | 不可越过的线 |
|---|---|---|---|
| **VC** | 时间、精力、实验室时段、差旅/科研资助额度 | 预算面板、占用与释放、来源和用途记录 | 不得充值购买成绩、能力、录取、先修豁免或排名 |
| **Card Pack** | 期刊征稿、会议、竞赛、实验室、实习和奖学金 | 按主题组织的透明“机会包”；打开前即可看全部内容、来源和资格 | 不做付费随机抽取、概率操纵、虚假稀缺或 FOMO |
| **Auction House** | 学生、项目、导师、社团和企业寻找彼此 | 搜索筛选、可解释推荐、双方表达意向与授权交换资料 | 不给人竞价，不出售曝光或匹配优先权，不把薪酬/名气等同于人的价值 |
| **Pass** | 会议通行证、数据库订阅、Workshop、实验室时段、差旅资助、奖学金资格 | `Entitlement Wallet` 展示真实权益、提供方、期限、领取条件与使用记录 | 不得花钱跳级、转学、绕过先修/审批或购买基本教育权利 |
| **Transfer Portal** | 转专业、转学、升学、交换、跳级/提前修读 | 资格解释、学分继承、时间/成本影响、所需材料和审批路径 | 系统只解释与模拟，不代替院校审批，不承诺结果 |

## 产品对象

### Opportunity

```text
id / title / provider / category
official_source_url / source_version / fetched_at
eligibility_rules / deadline / location / cost
benefits / obligations / application_route
verification_status / correction_route
```

### Learner-controlled Profile

```text
goals / interests / availability
verified_evidence[] / self_declared_evidence[]
sharing_scope / consent_version / expires_at
```

默认私密。学生决定是否使用某项证据进行匹配、是否向某个机会提供方披露，以及何时撤回。

### Eligibility Explanation

输出不能只有一个匹配分，应至少分成：

- **已满足：**可回到具体证据；
- **可能满足：**仍需人工或官方核验；
- **未满足：**缺少哪项、规则来源是什么；
- **未知：**数据不足，不能替用户猜；
- **下一步：**官方申请入口、补充材料或咨询对象。

### Match / Application Mirror

```text
discovered → saved → consented → interest_sent
→ mutual_interest → applied_externally → outcome_recorded
```

这只是进度镜像。正式申请、录取、雇佣、转专业或转学仍发生在相应权威系统。

### Entitlement

每项权益必须显示：提供方、真实价值/范围、领取资格、有效期、是否可转让、剩余额度、数据用途和官方凭证。系统不能自己发行“仿官方”资格。

## 一次最小可演示闭环

如果现场最终选择本模块作为唯一 P1，最小闭环应是：

1. 导入 5–10 条来自公开官方页面的演示机会，保存来源和抓取时间；
2. 学生仅勾选愿意用于匹配的目标与虚构/授权资料；
3. 系统解释一条“已满足 / 未满足 / 未知”的资格判断；
4. 学生保存机会并选择是否对外表达意向；
5. Box Score 展示判断依据、个人数据使用范围和纠错入口。

不进入最小闭环：真实招聘账号、批量抓取、自动投递、聊天、支付、真实奖学金发放、院校审批或“学生拍卖”。

## 与其他模块的接口

| 上游 / 下游 | 关系 |
|---|---|
| MyCareer 赛季中心 | 根据当前阶段呈现机会，不用机会数量定义学生价值 |
| Academic Mirror | 只读取被授权的课程/阶段证据，并保留权威等级 |
| Semester Resolver | 把机会所需课程或时间变成可解释约束，不自动改课表 |
| 智课工坊 | 经教师审核的作品或能力证据可由学生选择加入档案 |
| Performance Center | 展示准备度和下一步，不生成永久人格分 |
| Campus Life Hub | 提供社团、项目和同伴活动入口 |

## 公平、隐私与安全闸门

1. **零付费加权：**付费不能改变匹配顺序、资格判断或正式结果；
2. **零随机资格：**教育与职业机会不能靠抽卡概率分配；
3. **解释优先：**匹配理由和未知项比综合分更重要；
4. **本人控制：**未经明确同意，不把成绩、健康、家庭、财务、位置或敏感身份用于匹配；
5. **最小披露：**先匿名/最少信息表达兴趣，双方同意后再扩大共享；
6. **官方来源：**机会卡必须有来源、更新时间、验证状态和纠错渠道；
7. **人做决定：**导师、企业、学院与学生分别保留真实决定权；
8. **申诉与修正：**规则错误、过期机会和个人资料错误可以报告、撤回和追溯；
9. **不售卖学生：**不得将个人数据、简历或行为画像作为广告库存；
10. **不制造焦虑：**不使用倒计时恐吓、公开错失榜或“稀有学生”等措辞。

## 名称建议

对外不直接把 `VC`、`MyTEAM`、`Auction House` 当正式产品名，以免误解或侵犯品牌：

- `Opportunity Market / 机会市场`：机会发现与双向意向；
- `Opportunity Pack / 机会包`：完全透明的主题集合；
- `Capacity / 本周容量`：时间与精力预算；
- `Entitlement Wallet / 权益夹`：真实通行证、资助与订阅；
- `Pathway Portal / 路径门户`：转专业、转学与升学 What-if。

## 采用闸门与停损线

只有同时满足以下条件才进入现场实现：

- 智课工坊完整闭环已通过测试；
- 官方主题/赛道明确支持机会、教育、校园或人才匹配方向；
- 能使用公开、虚构或明确授权的数据；
- 团队能完成来源、同意、解释和纠错，而不只是做卡片列表；
- 预计实现不影响提交、路演与核心回退。

任一条件不满足，就只保留为路线图和 Pitch 中的扩展方向。
