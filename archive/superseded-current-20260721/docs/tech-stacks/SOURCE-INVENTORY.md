## 二、证据解释规则

RTF 的标题和内容结构表明，它是一份“可能需要用到的技术”学习资源集合，不是可直接证明当届赞助权益的正式清单。因此采用以下关系分类：

| 分类 | 含义 |
|---|---|
| 当届正式合作方 | AdventureX 2026 官网当前合作方区域明确列名 |
| 当届技术 / 设备支持方 | 官网当前列入该类别，但不等同于首席赞助商或独立赛道 |
| 官方硬件实验室资源 | FAQ 明确说可免费租用某类设备，但品牌、型号、数量仍可能未知 |
| 历史信号 | 官网故事区或往届内容出现过 Sponsor 身份，不能推出 2026 权益 |
| 技术参考 | RTF 收录，但当前官网合作方区域没有对应名称 |
| 二级教程 | 由课程或视频平台提供，不能替代项目官方文档和赛事权益说明 |

“合作方已列名”也不自动等于“指定 SDK、设备、额度已对本队开放”。精确 SKU、数量、Credit、账号、领取方式和赛道要求必须以终极指南、赛道规则或现场答复为准。
