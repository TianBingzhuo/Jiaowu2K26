# 智课工坊证据模式实现包

**用途**：把“AI 生成内容”从风险点变成可信产品能力  
**适用场景**：AdventureX 现场开发、路演 Demo、评委 Q&A  
**版本**：2026-06-23

---

## 1. 一句话定位

证据模式让每个脚本、题目、复习卡都能回看来源：来自哪一页 PPT、哪一句老师口播、为什么被标为考试重点。

这不是多做一个解释弹窗，而是在告诉评委：智课工坊不是简单生成课件，而是在做一条可审核的 AI 教研流水线。

---

## 2. 为什么值得做

| 常见质疑 | 证据模式的回答 |
|----------|----------------|
| AI 会不会乱编？ | 每段生成内容都绑定原始材料证据。 |
| 老师怎么放心发布？ | 老师能看到证据、修改文本、移除不可信内容。 |
| 和普通课件生成器有什么不同？ | 普通工具只给结果，智课工坊给结果、来源和审核路径。 |
| 考试重点怎么来的？ | 来自老师口头强调、PPT标题级概念、复杂度对比等可解释信号。 |

---

## 3. P0 交互流

```text
教师进入审核页
  -> 点击某一段 AI 脚本旁的“查看证据”
  -> 右侧抽屉显示来源片段
  -> 老师确认/修改/移除
  -> 通过后进入学生播放器和复习卡
```

P0 只需要做侧边栏，不需要完整知识图谱。

---

## 4. 数据入口

新增统一证据包：

```text
demo-pack/golden/evidence_bundle_bst.json
```

它把三类信息合并到一起：

| 类型 | 用途 |
|------|------|
| `evidence_items` | 原始证据，包括转写稿、PPT、老师口头强调 |
| `generated_objects` | AI 生成对象，包括脚本、题目、代码练习、复习卡 |
| `exam_signal_links` | 考试信号如何影响题目和复习卡 |

---

## 5. API 建议

```text
GET /api/demo/evidence-bundle
```

返回 `demo-pack/golden/evidence_bundle_bst.json`。

如果后端时间紧，可以先不做数据库，只要静态读取 JSON。

---

## 6. 前端组件建议

### 教师端

| 组件 | 说明 |
|------|------|
| `EvidenceButton` | 出现在脚本、题目、复习卡旁边，文案为“查看证据”。 |
| `EvidenceDrawer` | 右侧抽屉，展示来源、引用、置信度、老师操作。 |
| `ExamSignalBadge` | 展示 S/A 级重点，如“老师口头重点”“PPT核心概念”。 |
| `ReviewActionBar` | 通过、修改、移除、标为考试重点。 |

### 学生端

学生端不展示完整证据链，只显示轻量 badge：

```text
老师重点
来自PPT
来自口播
```

这样既可信，又不会打断学习体验。

---

## 7. 路演展示点

建议在 Demo 中用 20 秒展示：

1. 点开“左小右大”脚本旁的“查看证据”。
2. 右侧出现 PPT 第 2 页和老师口播证据。
3. 点击“标为考试重点”。
4. 切到学生端，看到中途题目和最后复习卡都带着这个重点。

路演话术：

> 这里我们不是让 AI 凭空生成内容，而是让它从老师已有材料里提取、生成、再交给老师审核。每个输出都能追溯到来源。

---

## 8. 验收标准

| 验收项 | 通过标准 |
|--------|----------|
| 证据包可读取 | `/api/demo/evidence-bundle` 返回 JSON。 |
| 教师审核页可打开证据 | 点击至少 3 个对象能看到对应来源。 |
| 考试信号可解释 | S 级重点能显示来自老师口头强调或 PPT 核心页。 |
| 老师可操作 | 至少有“通过”“修改”“移除”三个按钮或状态。 |
| 学生端不复杂 | 只展示 badge，不展示长证据文本。 |

---

## 9. 现场兜底

如果证据模式来不及接进真实产品：

1. 使用静态原型页：

```text
demo-pack/fallback/screenshots/evidence_mode_mock.html
```

2. 在 PPT 中放截图。
3. 话术改成“我们已经把证据链数据结构准备好，现场版本优先展示核心路径”。

---

## 10. 开发优先级

| 优先级 | 任务 |
|--------|------|
| P0 | 静态读取 `evidence_bundle_bst.json` 并展示证据抽屉。 |
| P0 | 在教师审核页给脚本和题目加“查看证据”。 |
| P0 | 学生端给题目和复习卡显示“老师重点”badge。 |
| P1 | 老师操作结果写回本地状态。 |
| P1 | 支持按证据来源筛选：PPT、口播、考试信号。 |
| P2 | 多课程、多老师、多版本证据链。 |
