## 这批信息真正说明了什么

### 1. 组队群是最新需求，主群和交流群是履历与演变记录

组队群 61 条最接近当前状态；另外两组补齐了早期自荐、旧版要求和项目背景。不能只看最新一条：例如温标林的新帖只说“找产品”，旧帖却给产品经理加了 DL 硬要求。

### 2. Agent 和硬件供给很足，能把技术变成作品的人仍然稀缺

全栈、Agent、RAG、嵌入式、机器人、CV、3D 打印反复出现。真正被多支成型队伍明确寻找的是：真实问题、产品取舍、用户验证、Demo 故事、PPT、路演、商业判断和跨角色协调。这正是你应该占住的位置。

### 3. “产品”不是一个统一岗位

有的队伍要产品定义和功能优先级；有的其实要 Figma / 海报；有的要销售获客；有的把产品、运营、剪辑、宣传塞进同一个席位。私聊必须问“希望我现场交付什么文件或结果”，不能只听到“缺产品”就默认匹配。

### 4. 新增候选里出现了更适合你性格的协作信号

Kim、章子赫、许松、王毅成都强调共同决策、真实问题、赛后朋友或不把夺冠放在第一位。它们比“最后席位、立即冲刺”更符合你的佛系，但仍要确认工程责任人和现场范围。

### 5. 很多漂亮想法仍然过大

现实世界 Git、主动式生活 Agent、AI 饮品机、脑电、数字生命、Agent OS、手机控制、个人星球、Social Cosmos 都有记忆点，也同时踩中隐私、硬件、平台权限、实时链路或范围风险。你加入后的价值是砍出一条可验证闭环，不是继续加世界观。

### 6. 未成年选手比例不低

样本里明确出现 14–17 岁成员。所有联系都只围绕项目、角色和公开协作；不使用暧昧、择偶、外貌或性别筛选表达。年龄也不是能力判断，但需要更清晰的沟通、署名、作品归属和安全边界。

### 7. 医疗、心理、脑电和中医项目要额外保守

健康方向不是神秘学，但“健康预警、医疗决策、诊疗参考、治疗效果”等表述需要专业证据、数据合规和明确的非诊断边界。脑电项目也应先问信号范式、现场可验证任务和伦理边界。不能把不可验证的疗效当卖点。

## 你的对外定位

| 能力 | 可以承诺 | 不要承诺 |
|---|---|---|
| 产品定义 | 用户问题、价值命题、优先级、MVP 范围 | “我有一个必胜 Idea” |
| 技术方案协同 | 模块拆解、接口逻辑、风险、备选路线 | 独立扛下不熟悉的核心开发栈 |
| Demo 与路演 | 故事线、PPT 结构、演示脚本、演讲、答辩 | 把未完成能力包装成既有成果 |
| 头脑风暴 | 发散后用用户价值和可实现性收敛 | 无限发散、不肯删功能 |
| AI 辅助 | 查资料、理解方案、文档、测试与联调沟通 | 用“有 AI”替代真实工程责任人 |
| 团队协作 | 主动同步、推进分工、跨角色翻译、现场应变 | 无边界地“什么都帮一点” |

一句话版本：

> 我是偏产品与解决方案的现场型队友，能把脑洞收敛成可执行方案，把复杂技术讲成人能听懂的故事，也能扛 Demo、路演和答辩；核心工程栈我不会装熟，但会认真理解、拆解和配合。

1. 现在几个人、还剩什么角色、这个位置是否仍开放；
2. 希望你现场交付什么具体结果，而不只说“负责产品”；
3. 谁稳定扛核心工程，谁负责最终集成；
4. Topic 公布后是否可以推翻赛前 Idea，怎样共同决策；
5. P0 能否压成一条三分钟可验证链路；
6. 作息、同步频率、冲突处理以及是否默认通宵；
7. 哪些资产赛前已存在，本届准备从零新增什么；
8. 作品归属、开源 / 商业化意愿，以及彼此是否真的聊得来。

## 最终选择原则

如果两支队伍都愿意要你，按这个顺序选：

1. 你有清晰、独立、可验收的产品 / 方案 / Pitch 责任；
2. 至少一人稳定扛核心工程与最终集成；
3. Topic 后可以共同推翻赛前 Idea；
4. P0 是一条三分钟可验证链路；
5. 沟通舒服、边界清楚、不同意见能直接说；
6. 不靠人为稀缺、通宵崇拜和情绪压力推动决策；
7. 现有资产与本届新增边界说得清；
8. 比赛后即使不创业，也愿意维护作品或继续做朋友。

履历是加分项，角色互补、真实交付和相处方式才是决定项。
