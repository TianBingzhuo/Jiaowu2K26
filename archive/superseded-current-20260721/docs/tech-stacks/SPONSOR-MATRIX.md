## 一、赛事事实基线

- 时间：2026 年 7 月 22 日至 26 日，杭州；
- 核心创造时间：72 小时；
- 参赛方式：且只能选择一个主题，可选择 1–6 个符合条件的合作方赛道；
- 通用资源承诺：算力、AI Credit、硬件和 3D 打印资源可免费使用；
- 硬件实验室已公开的设备类别：Bambu Lab 3D 打印机、Vision Pro、Nothing 手机、无人机、机械臂、智能眼镜、芯片与机器人套件；

- 尚未公开：逐品牌硬件 SKU、数量、每队限额、预约 / 归还、技术人员时段和赛道详细规则。

## 四、候选技术能力核验摘要

### 阶跃星辰

阶跃星辰开放平台目前覆盖语言、视觉、图像编辑、语音 / TTS、函数调用和 Agent 工具使用，并提供兼容常见 API 调用方式。它与课程材料理解、结构化课件生成和语音互动高度匹配，同时具备当届首席赞助关系。

优先级来自“产品适配 + 当届身份”，不是对现场额度的假设。官方入口：[阶跃星辰开放平台](https://platform.stepfun.com/)。

### 飞书

多维表格的表、字段、视图、记录与开放 API 很适合承载：

- source ID、原文件、页码 / 时间戳；
- AI 生成对象与证据片段；
- 待审核、已修改、通过、移除；
- 审核人、时间、原因和发布状态。

但配置应用权限和文档授权可能比本地数据库更慢，因此保留“本地数据合同为 P0、飞书为可视化协作层”的回退结构。官方入口：[飞书开放平台](https://open.feishu.cn/)。

### 科大讯飞

官方语音能力通常通过 WebSocket / SDK 提供 ASR 与 TTS，依赖 AppID、APIKey、APISecret 和服务额度。它对“老师讲解转写、学生口头作答、语音反馈”有直接价值。

如果浏览器原生录音 + 单次云端转写已经足够，不应再叠加 TEN 和 Agora。官方入口：[讯飞开放平台](https://www.xfyun.cn/)。

### Qoder

Qoder 是 Agentic Coding 工具，覆盖代码理解、上下文、长期任务、CLI / IDE 等开发工作流。它能提高正式开赛后的实现效率，但不是智课工坊的用户功能，也不能作为项目价值本身。

团队已经使用 Codex，不应为了赞助身份在现场中途迁移全部工作流。可在赛道规则和账号可用后，只让熟悉它的成员试用。官方入口：[Qoder](https://qoder.com/)、[Qoder Docs](https://docs.qoder.com/)。

### 百度秒哒

秒哒主打通过自然语言、文档和图片生成应用并快速发布。它可能显著缩短 UI 验证时间，但需要确认生成物可导出性、后端 / 数据边界、原创性要求和供应商锁定。

判断：适合做快速界面候选，不在赛前生成任何参赛页面。官方入口：[百度秒哒](https://www.miaoda.cn/)。

### PICO

PICO 开发者平台支持 OpenXR、Unity、Unreal、Web / WebXR、Android 与 PCVR。空间课程有强现场辨识度，但内容资产、交互和设备调试会抢占核心闭环时间。

判断：只有团队已有 Unity / OpenXR 经验、设备在前 2 小时可用、并且空间交互直接解决学习问题时采用。官方入口：[PICO Developer](https://developer.picoxr.com/)。

### AGILE-X

AGILE-X 提供移动机器人底盘、ROS / ROS 2 套件、LIMO、PiPER 机械臂和 Cobot 等。它能做具身课堂助教，但精确产品的 Ubuntu / ROS 版本、SDK 与安全边界差异很大。

判断：只在现场给出已预配置设备、导师支持和清晰演示空间时进入 P1。官方入口：[AGILE-X](https://global.agilex.ai/)。

## 五、当前推荐顺序

### Primary 候选骨架

1. 一个当届可用的模型 API，先测阶跃星辰；
2. 一条自有、极小的 Web 业务链；
3. 本地结构化数据保存 source、生成、审核和发布状态；
4. 全链路只演示一个真实课程对象；
5. 云端失败时有明确、非伪装的现场回退。

### Secondary 候选

- 教师协作强：飞书多维表格；
- 端侧视觉强：D-Robotics；
- 低功耗语音 / IoT：TuyaOpen；
- 语音质量强：科大讯飞；
- 小而醒目的物理反馈：Nothing Glyph。

### 高风险 P1

- PICO 或 Vision Pro 空间学习，二选一；
- AGILE-X 或 Seeed 机械臂，二选一；
- TEN + Agora 实时课堂；
- Injective 可验证凭证；
- ModelScope 本地模型或 LoRA 训练。
