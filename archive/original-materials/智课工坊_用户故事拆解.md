# 智课工坊（SmartCourse Studio）用户故事拆解

**项目代号**：SCS  
**文档版本**：v1.0  
**日期**：2026-06-23  
**拆分粒度**：黑客松日级（Day1-Day5）  
**估算体系**：Fibonacci（1/2/3/5/8）  
**团队容量**：4人 x 8 SP/天 = **32 SP/天**，5天总容量 **160 SP**

---

## 一、需求全貌

### 1.1 涉及角色

| 角色 | 描述 | 核心场景 |
|------|------|---------|
| **教师（Teacher）** | 大学课程教师，上传录音/课件，审核并生成动画课程 | 上传材料 → 审核脚本 → 确认生成 → 发布课程 |
| **学生（Student）** | 大学生，观看动画课程并完成互动答题 | 观看动画 → 答题互动 → 代码练习 → 复习指南 |
| **管理员（Admin）** | 大学/院系管理者，配置平台信息 | 配置校名/院系 → 绑定课程 |

### 1.2 核心流程（End-to-End Pipeline）

```
教师上传录音/视频 ──→ ASR转写为文本
                      ↓
教师上传课件PPT  ──→ 提取文本/图片/公式
                      ↓
            合并结构化数据
                      ↓
           AI生成教学脚本（洋葱风格）
                      ↓
        【教师审核编辑】预览 → 修改 → 确认
                      ↓
      ┌───────────┬───────────┬──────────┐
      ↓           ↓           ↓          ↓
  动画渲染     TTS配音     BGM选曲    出题引擎
      ↓           ↓           ↓          ↓
      └───────────┴───────────┴──────────┘
                      ↓
           互动播放器（动画+出题+代码测试）
                      ↓
           复习指南生成（副产品）
```

### 模块 F1：录音/视频转文字

#### US-F1-01：上传录音/视频文件

**角色**：作为教师（Teacher）  
**需求**：我希望上传课程录音或视频文件（MP3/WAV/MP4）  
**价值**：以便系统能够自动将语音内容转为文字，作为后续脚本生成的输入  
**优先级**：P0  
**Story Points**：3  
**排期日**：Day 1  
**负责**：P1（全栈）

**Acceptance Criteria**：
- [ ] Given 教师已登录平台, When 上传一个5-10分钟的MP3录音文件, Then 系统显示上传进度条，上传完成后状态变为"转写中"
- [ ] Given 教师已登录平台, When 上传一个MP4视频文件, Then 系统自动提取视频中的音频轨道并进入转写流程
- [ ] Given 教师已登录平台, When 上传一个超过50MB的文件, Then 系统提示"文件大小超过限制，请上传50MB以内的文件"
- [ ] Given 教师已登录平台, When 上传不支持的格式（如WMA）, Then 系统提示"不支持的音频格式，请上传MP3/WAV/MP4格式文件"

**依赖**：无（先行Story）  
**技术备注**：后端FastAPI接收文件，存储到临时目录，触发ASR pipeline。前端使用shadcn/ui的File Upload组件。

**INVEST校验**：
| 原则 | 结果 | 说明 |
|------|------|------|
| I | ✅ | 独立可交付，上传功能不依赖ASR实现 |
| N | ✅ | 描述"做什么"，未指定实现方式 |
| V | ✅ | 教师可感知——文件上传成功即有价值 |
| E | ✅ | 团队可快速估算 |
| S | ✅ | 1天内可完成 |
| T | ✅ | AC具体可测试 |

#### US-F1-02：ASR语音转写为文本

**角色**：作为教师（Teacher）  
**需求**：我希望系统将上传的录音/视频自动转写为带时间戳的文字  
**价值**：以便获得结构化的文本内容，作为AI脚本生成的原始素材  
**优先级**：P0  
**Story Points**：5  
**排期日**：Day 1  
**负责**：P3（AI）

**Acceptance Criteria**：
- [ ] Given 一段5分钟课程录音已上传完成, When 系统触发ASR转写, Then 3分钟内返回转写文本，准确率≥80%（以人工抽检10句话为准）
- [ ] Given 转写完成, When 教师查看转写结果, Then 文本包含时间戳标记（每30秒一个段落），可在编辑界面查看
- [ ] Given 录音中包含专业术语（如"递归""多态"）, When 转写完成后, Then 术语识别率≥60%（允许后续人工修正）
- [ ] Given ASR服务暂时不可用, When 系统触发转写, Then 显示"转写服务繁忙，请稍后重试"，并保留文件等待重新触发

**依赖**：US-F1-01（需要上传接口就绪）  
**技术备注**：优先使用OpenAI Whisper API或阿里云ASR。P3上午完成ASR方案选定和部署，下午与上传接口联调。

**INVEST校验**：
| 原则 | 结果 | 说明 |
|------|------|------|
| I | ✅ | 可独立于后续脚本生成使用 |
| N | ✅ | 未指定必须用Whisper还是其他方案 |
| V | ✅ | 教师获得可读的文本即有价值 |
| E | ✅ | 中等复杂度，团队可估算 |
| S | ✅ | 1天内可完成 |
| T | ✅ | 准确率可量化测试 |

### 模块 F2：课件PPT内容提取

#### US-F2-01：上传并解析PPT文件

**角色**：作为教师（Teacher）  
**需求**：我希望上传课件PPT文件（.pptx），系统自动解析其内容  
**价值**：以便将课件中的知识点、图片、备注纳入脚本生成的上下文  
**优先级**：P0  
**Story Points**：3  
**排期日**：Day 1  
**负责**：P1（全栈）

**Acceptance Criteria**：
- [ ] Given 教师已登录平台, When 上传一个含10-30页的.pptx文件, Then 系统在30秒内完成解析，显示"解析完成"状态
- [ ] Given PPT包含文本+图片+备注, When 解析完成, Then 每页的文本内容、图片（以base64存储）、演讲者备注均被提取并可预览
- [ ] Given 上传的是.ppt（旧格式）文件, When 系统接收文件, Then 提示"请上传.pptx格式文件，不支持旧版.ppt格式"

**依赖**：无（与US-F1-01并行）  
**技术备注**：使用python-pptx库提取内容，P1下午实现。前端上传组件复用US-F1-01的File Upload。

**INVEST校验**：
| 原则 | 结果 | 说明 |
|------|------|------|
| I | ✅ | PPT解析独立于ASR，可并行开发 |
| N | ✅ | 未指定具体解析库 |
| V | ✅ | 教师上传PPT即获得结构化数据 |
| E | ✅ | 简单任务 |
| S | ✅ | 半天可完成 |
| T | ✅ | AC可验证 |

#### US-F2-02：PPT内容结构化输出

**角色**：作为教师（Teacher）  
**需求**：我希望PPT内容被结构化为"每页一个知识点"的JSON格式  
**价值**：以便后续AI脚本生成和动画渲染可以按知识点粒度处理  
**优先级**：P0  
**Story Points**：3  
**排期日**：Day 1  
**负责**：P1（全栈）

**Acceptance Criteria**：
- [ ] Given PPT解析完成, When 系统输出结构化数据, Then 返回JSON格式包含：每页标题、正文文本列表、图片URL列表、备注文本、页码
- [ ] Given PPT中包含数学公式（以图片或LaTeX形式）, When 结构化输出时, Then 公式内容被标记为"formula"类型字段，保留原始内容
- [ ] Given PPT某页只有图片没有文字, When 结构化输出时, Then 该页仍被保留，文本字段为空数组，图片字段正常输出

**依赖**：US-F2-01（依赖PPT解析完成）  
**技术备注**：输出格式需与F3脚本生成模块的输入接口对齐。

**INVEST校验**：

### 模块 F3：AI教学脚本生成

#### US-F3-01：从转写文本生成洋葱风格教学脚本

**角色**：作为教师（Teacher）  
**需求**：我希望系统根据转写文本和PPT内容自动生成5-8分钟的洋葱风格教学脚本  
**价值**：以便将冗长的课程录音精炼为短小精悍、节奏感强的动画脚本  
**优先级**：P0  
**Story Points**：5  
**排期日**：Day 2  
**负责**：P3（AI）

**Acceptance Criteria**：
- [ ] Given ASR转写文本和PPT结构化数据已就绪, When 教师点击"生成脚本", Then 系统在60秒内返回完整教学脚本，包含开场白、知识点讲解、过渡语和总结
- [ ] Given 脚本已生成, When 教师查看脚本, Then 脚本包含场景描述（动画指令）、角色台词（配音文本）、知识点标签三个层次的信息
- [ ] Given 转写文本质量较低（ASR准确率<60%）, When 生成脚本时, Then 系统仍输出可用脚本，并在低置信度段落标注"[建议人工复核]"
- [ ] Given LLM API调用超时, When 生成脚本, Then 系统提示"生成超时，请重试"，不返回残缺脚本

**依赖**：US-F1-02（ASR转写完成）、US-F2-02（PPT结构化完成）  
**技术备注**：P3负责prompt工程，使用GPT-4/Claude/DeepSeek。Prompt需包含洋葱学院风格示例作为few-shot。

**INVEST校验**：
| 原则 | 结果 | 说明 |
|------|------|------|
| I | ✅ | 脚本生成可独立于动画渲染验证 |
| N | ✅ | 未指定LLM型号 |
| V | ✅ | 教师获得可读脚本即有核心价值 |
| E | ✅ | prompt工程量可估算 |
| S | ✅ | 1-2天可完成 |
| T | ✅ | 脚本质量可人工评审 |

#### US-F3-03：脚本格式化输出（JSON Schema）

**角色**：作为教师（Teacher）  
**需求**：我希望教学脚本以标准化JSON格式输出  
**价值**：以便下游动画渲染、TTS配音、出题引擎等模块可以直接消费  
**优先级**：P0  
**Story Points**：2  
**排期日**：Day 2  
**负责**：P3（AI）

**Acceptance Criteria**：
- [ ] Given 脚本生成和知识点拆分完成, When 输出JSON, Then JSON包含以下顶级字段：`segments[]`（场景列表）、`knowledgePoints[]`（知识点列表）、`metadata`（课程标题/时长/学科）

**优先级**：P0
