# 文字版复习指南生成规范

**所属模块**：智课工坊（SmartCourse Studio）— 复习指南生成引擎  
**版本**：v1.0  
**日期**：2026-06-23  
**说明**：本文档定义了平台"文字版复习指南"自动生成引擎的方法论、输出规范和质量标准。基于考情工程方法论（Dunlosky et al. 2013），从课程录音转写稿中提取考试信号并生成结构化的复习材料。

---

## 一、核心理念：考情工程

复习指南不是知识点的简单罗列，而是**以考试信号为导向的情报产品**。老师上课时的语言暗示（"这个很重要""考试会考""掌握到什么程度"）比任何网络资料都值钱。期末考试是老师出题，所以"这个老师怎么想"比"这门学科是什么"更重要。

**信号优先级排序（从高到低）**：

| 优先级 | 信号类型 | 描述 |
|--------|---------|------|
| P1 | 老师明确声明 | "必须记住""考试会考""这个你们必须掌握" |
| P2 | 最后一两节课/复习课 | 复习课内容通常覆盖考试重点 |
| P3 | 作业和课堂例题 | 老师花大量时间讲解的例题和作业题 |
| P4 | PPT 标题级知识点 | 章节标题和小节标题通常代表核心概念 |
| P5 | 反复出现的概念 | 重复 = 重视，多次讲解的知识点优先 |
| P6 | 教材补充内容 | 课件中未覆盖但教材有的内容 |

## 二、课程材料预处理

### 2.1 输入材料

平台从以下来源获取原始材料：

| 来源 | 处理方式 | 输出 |
|------|---------|------|
| 课程录音转写稿 | ASR 转写 + 后处理（术语校正、分段） | 结构化文本（按时间戳分段） |
| 课程视频转写稿 | 同上 + 关键帧提取 | 结构化文本 + 关键帧图片 |
| 课件 PPT | python-pptx 提取文本 + 图片 + 备注 | PPT 内容文本 + 图片资源 |
| 教师手写笔记/板书 | OCR 识别 | 文本 + 图片 |

### 2.2 转写文本预处理规则

在提取考试信号之前，需要对 ASR 转写文本做以下预处理：

1. **术语校正**：建立学科术语词典，修正 ASR 中的同音词错误（如"花椒球"→"邦加球"、"欧光"→"o光"）
2. **分段对齐**：将转写文本与 PPT 页码对齐，建立"转写段落 ↔ PPT 页码"的映射关系
3. **口语过滤**：移除无信息量的口语填充词（"嗯""就是说""对吧"等）
4. **公式标注**：将口述的公式转换为标准数学符号（"x的平方"→ x²）

## 三、考试信号提取与优先级标注

### 3.1 考试形式识别

从转写稿中提取以下考试元信息：

| 字段 | 提取方式 | 示例 |
|------|---------|------|
| 考试形式 | 关键词匹配："开卷""闭卷""带计算器" | 闭卷 |
| 题型 | 关键词匹配："选择题""计算题""简答题""论述题""画图题" | 选择+计算+简答 |
| 分值结构 | 数字提取："选择题每题2分""计算题每题15分" | 选择30分+计算45分+简答25分 |
| 考试范围 | 否定信号："这个不考""后面不用看了" + 肯定信号："第三四章重点" | Ch1-Ch4 |
| 允许带材料 | "可以带一页A4纸""可以带计算器" | 允许一页A4 |

### 3.2 知识点优先级标注（S/A/B三级）

| 等级 | 标签颜色 | 判断依据 | 复习建议 |
|------|---------|---------|---------|
| **S（必考核心）** | 红色 | 老师明确说考 / 反复强调 / 有完整例题 / 花大量时间推导 | 完整做卡片 + 模拟题 + 必须能默写或计算 |
| **A（高频考点）** | 橙色 | PPT 标题级 / 作业涉及过 / 老师提过"比较重要" | 知识点卡片 + 至少1道模拟题 |
| **B（了解即可）** | 绿色 | 课件里有但老师没重点讲 / 一笔带过的内容 | 只列名称 + 一句话核心 |

### 3.3 题型预测

根据知识点的特征预测可能的题型：

| 知识点特征 | 可能题型 | 出题方式 |
|-----------|---------|---------|
| 有明确公式和计算过程 | 计算题 | 给参数求结果 |
| 有多个概念需要区分 | 简答题/选择题 | 比较A和B的异同 |
| 有推导过程 | 证明/推导题 | 从A推到B |
| 有图形/图像表示 | 画图题 | 画出/标出XX |
| 有适用条件/限制 | 判断题/简答题 | XX的适用条件是什么 |
| 有实际应用场景 | 论述题 | 解释XX原理及其应用 |

## 四、复习指南文件结构规范

### 4.1 文件组织

每门课程的复习指南由以下文件组成：

```
{课程名}/
├── 00_考情情报表.md           # 最先输出：考试信号汇总 + S/A/B分级
├── 01_公式概念库.md           # 全部公式/概念汇总，按章节排列
├── 02_知识点卡片库.md         # S/A/B分级的全部知识点，含模拟题
├── 03_闭卷背诵包.md           # 闭卷科目：一页骨架 + 触发器清单
│   或 03_开卷战斗索引.md      # 开卷科目：定位索引
├── 04_模拟题与答案.md         # 每章3-5道模拟题 + 答案框架
├── 05_最后24小时清单.md       # 考前最后一轮精简内容
└── (可选) 06_概念辨析.md      # 容易混淆的概念对比
```

### 4.2 各文件内容规范

#### 00_考情情报表

这是整个复习指南的"总指挥"，最先输出。内容包括：

- 考试形式（开卷/闭卷、题型、分值）
- 考试范围（哪些章节考、哪些不考）
- 知识点清单（按章节排列，标注S/A/B等级）
- 强信号摘要（老师原话引用）
- 风险点提示（转写不清、范围含糊的地方）
- 各章节关联关系图

#### 01_公式概念库

按章节汇总所有公式和核心概念：

```markdown
## 第N章：{章节名}

### 公式1：{公式名}
$$公式表达式$$

**变量说明**：
- 变量A：含义，单位
- 变量B：含义，单位

**适用条件**：{什么情况下能用}

**数值例子**：
已知 A=..., B=...
代入公式：... = **{结果}**
解读：{这个结果的物理/实际意义}
```

#### 02_知识点卡片库

每个知识点一张卡片，格式：

```markdown
### {知识点名称} [S/A/B]

**核心内容**：一句话总结

**详细解释**：2-3句展开

**老师信号**："{老师原话}"（第N次课）

**课件位置**：PPT第X页

**可能题型**：计算 / 简答 / 画图

**最低掌握**：能背 / 能算 / 能解释 / 能套公式

**模拟题**：
Q: {题目}
A: {答案关键词和步骤}
```

#### 03_闭卷背诵包 或 开卷战斗索引

**闭卷科目**——三层压缩法：
1. 一页骨架：整科核心公式+概念压到一页
2. 高频题型模板：每类题型的固定解题步骤
3. 触发器清单：看到什么关键词 → 用什么公式/定理

**开卷科目**——战斗索引：
1. 题型-资料定位表：看到什么题型翻哪些页
2. 公式/定义/关键词索引（带页码）
3. 典型题解题步骤
4. 老师强调点 + 易错点

#### 04_模拟题与答案

每章3-5道题，覆盖所有S级知识点。题目来源：
1. **老师例题改参数**：把课上例题换数字/换条件/换问法
2. **PPT标题变问题**：把标题改成简答题
3. **作业题改问法**：换个角度问
4. **跨知识点对比**：把分散在多页的概念整合对比

**答案格式**：
```
思路 → 关键公式 → 代入求解 → 答案 + 解读
```

#### 05_最后24小时清单

考前最后一轮要看的精简内容，不超过3页：
- 闭卷：默写一页骨架 + 过触发器清单
- 开卷：快速翻一遍索引确认定位速度
- 所有S级知识点的"一句话核心"汇总
- 最易混淆的概念对比（不超过5组）

## 五、HTML讲义生成规范

除 Markdown 文件外，平台还应生成可直接在浏览器中打开的 HTML 讲义，支持交互式学习。

### 5.1 CSS设计体系

```css
:root {
  --bg: #fafafa;
  --card: #ffffff;
  --accent: #2563eb;
  --accent-light: #dbeafe;
  --text: #1e293b;
  --text-light: #64748b;
  --border: #e2e8f0;
  --highlight: #fef3c7;
  --formula-bg: #f1f5f9;
  --tip-bg: #ecfdf5;
  --warn-bg: #fef2f2;
  --quiz-bg: #f5f3ff;
  --quiz-accent: #7c3aed;
  --correct-bg: #ecfdf5;
  --correct-accent: #10b981;
}
```

### 5.2 核心组件

| 组件 | 用途 | 交互 |
|------|------|------|
| `.formula-box` | 公式展示框 | 悬停显示变量解释 |
| `.var-explain` | 变量说明 | 紧跟公式下方 |
| `.tip` | 提示框（💡） | 绿色底 |
| `.warn` | 警告框（⚠️） | 红色底，易错点 |
| `.highlight` | 行内高亮 | 黄色底 |
| `.quiz-block` | 你试试练习（🎯） | 含可折叠答案 |
| `.tag-s/.tag-a/.tag-b` | 优先级标签 | 红/橙/绿 |

### 5.3 教学节奏

每个知识点按以下节奏展开：

```
公式 → 大白话解释 → 代入数字算一遍 → 你试试练习 → 下一个
```

**关键规则**：
- 每个公式必须有变量解释和数值例子
- 每2-3个公式之间有"你试试"练习
- 练习题答案用 `<details><summary>查看答案</summary>` 折叠
- 答案要完整：数值结果 + 实际解读

### 5.4 公式渲染

使用 KaTeX（CDN 注入 `<head>`）渲染数学公式。矩阵使用 CSS inline-grid + `::before`/`::after` 伪元素画圆角括号（禁止使用 Unicode 括号分段字符）。

## 六、补充能力（超越基础考情工程）

以下能力是对基础考情工程方法论的增强，建议在 Phase 1-2 中逐步实现：

### 6.1 知识图谱自动生成

从转写文本中提取知识点之间的关联关系，自动生成课程知识图谱：

- **节点**：知识点/概念/公式
- **边**：前置关系（A是B的基础）、对比关系（A和B容易混淆）、应用关系（A用于解决B类问题）
- **输出**：可交互的 SVG/Canvas 知识图谱，学生可以点击查看每个知识点详情

### 6.2 思维导图导出

将复习指南内容自动导出为思维导图格式：

- **核心节点**：课程名
- **一级节点**：章节
- **二级节点**：S/A级知识点
- **三级节点**：公式/概念/易错点
- **输出**：Mermaid/PlantUML 格式，可导入 XMind/MindNode

### 6.3 间隔重复计划生成

根据考试日期和知识点优先级，自动生成复习时间表：

| 天数 | 做什么 | 为什么 |
|------|--------|--------|
| Day 1 | S级完整卡片 + 第一次自测 | 首次记忆编码 |
| Day 2 | S级第二次自测 + A级卡片 | 24小时后第一次复习 |
| Day 4 | S级第三次自测 | 3天后第二次复习 |
| Day 7 | 全科模拟练习 | 7天后第三次复习 |
| 考前1天 | 一页骨架默写 + 触发器清单 | 最终巩固 |

### 6.4 自测评分机制

学生完成模拟题后，平台自动评分并给出反馈：

| 评分维度 | 判断标准 | 反馈 |
|---------|---------|------|
| 关键词命中 | 答案中包含所有关键词 | 完整/遗漏XX关键词 |
| 步骤完整性 | 计算步骤是否完整 | 缺少第X步 |
| 数值正确性 | 最终答案是否正确 | 正确/偏差XX% |
| 概念理解 | 解释是否准确 | 混淆了A和B |

### 6.5 薄弱点追踪

记录学生每次自测的表现，自动识别薄弱知识点：

- 标记连续答错2次以上的知识点
- 推荐针对性的复习材料和补充练习
- 生成"个人薄弱点清单"（考前重点看）

### 6.6 备考策略建议

根据考试形式自动生成个性化的备考策略：

**闭卷科目**：
- 时间分配建议：20%看资料 + 50%自测/默写 + 30%查漏补缺
- 空白纸测试法：合上材料凭记忆写，写完对照查漏
- 费曼检测法：用大白话讲解，卡住的地方就是没懂的地方

**开卷科目**：
- 重点练"30秒定位"能力
- 考前至少做2-3次计时模拟练习
- 资料不是越多越好，每个知识点只保留最精炼版本

## 七、质量检查清单

每份复习指南生成后，自动执行以下检查：

- [ ] 所有公式都有变量解释和数值例子
- [ ] 每2-3个公式之间有"你试试"练习
- [ ] S/A/B优先级与考情情报表一致
- [ ] 每章有3-5道模拟题覆盖所有S级知识点
- [ ] 模拟题答案格式为：思路→公式→求解→答案+解读
- [ ] HTML讲义中公式使用 KaTeX 渲染
- [ ] HTML讲义中矩阵使用 CSS grid 方案
- [ ] 闭卷科目有背诵包，开卷科目有战斗索引
- [ ] 最后24小时清单不超过3页
- [ ] 无遗漏：转写稿中的每个考试信号都被提取

## 八、生成引擎 Prompt 规范

平台的 LLM 生成复习指南时，应遵循以下 prompt 结构：

```
你是一个考试复习专家。你的任务是从课程录音转写稿中提取考试信号并生成结构化的复习指南。

【输入】
- 课程转写文本（含时间戳）
- 课件PPT内容（可选）
- 考试信息（形式、范围、题型，如果老师提到过）

【输出要求】
1. 首先输出考情情报表：提取所有考试信号，标注知识点优先级
2. 然后输出公式概念库：按章节汇总公式和概念
3. 然后输出知识点卡片库：每个知识点一张卡片（含模拟题）
4. 根据考试形式输出背诵包或战斗索引
5. 最后输出模拟题集和最后24小时清单

【标注规则】
- S级：老师明确说考 / 反复强调 / 有完整例题
- A级：PPT标题级 / 作业涉及 / 老师说"比较重要"
- B级：课件有但没重点讲 / 一笔带过

【质量要求】
- 每个公式必须有变量解释和数值例子
- 模拟题答案必须完整：思路→公式→求解→答案+解读
- 引用老师原话作为考试信号的证据
- 标注信息来源（第几次课、PPT第几页）
```

## 九、与动画课程的联动

复习指南与动画课程是互补关系，不是替代关系：

| 场景 | 用动画课程 | 用复习指南 |
|------|-----------|-----------|
| 首次学习知识点 | ✅ 动画讲解更直观 | |
| 复习巩固 | | ✅ 快速查阅公式和概念 |
| 考前冲刺 | | ✅ 一页骨架 + 触发器清单 |
| 开卷考试 | | ✅ 战斗索引快速定位 |
| 做模拟题 | 看动画讲解薄弱部分 | ✅ 做题 + 对答案 |
| 理解困难 | ✅ 动画可视化 | 看公式 + 数值例子 |

**联动设计**：
- 复习指南中的每个知识点卡片，链接到对应的动画课程片段
- 动画课程中的"你试试"练习，链接到复习指南中的详细解答
- 学生答题错误后，推荐对应的动画课程片段重新学习
