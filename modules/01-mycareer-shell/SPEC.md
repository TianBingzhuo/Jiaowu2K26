# MyCareer 赛季中心 · 功能规格

> **模块编号：** F-002 · **优先级：** P0 轻外壳
> **基线日期：** 2026-07-21
> **状态：** 待验证规格，不是完成声明

---

## 1. 使命

把课程工具放回学生从入学到毕业的连续上下文，让"现在做什么、为什么、下一步去哪"始终可见。

## 2. P0 范围

赛季中心是**壳**，不复制全部模块的数据。P0 只需要证明：

```
当前学期（赛季首页）
  → 一门课程（阵容卡片）
  → 智课工坊互动（点击"开始学习"跳转 F-001）
  → Box Score（查看学习统计，跳转 F-001 Replay）
```

## 4. P0 User Stories（4 个）

### US-01：查看当前赛季（F002-03）
**角色：** 学生 · **优先级：** P0
**需求：** 我进入首页能看到当前学期的整体情况
**AC：**
- [ ] 显示赛季名称（如"第 3 赛季 · 2026 秋季"）
- [ ] 显示赛季进度条（当前 / 总赛季数）
- [ ] 列出所有课程阵容卡片
- [ ] 显示近 7 天内的截止日

### US-02：查看课程阵容（F002-04）
**角色：** 学生 · **优先级：** P0
**需求：** 我能看到每门课程的当前状态和下一步行动
**AC：**
- [ ] 每张卡片显示：课程名、学分、角色（必修/选修）、进度百分比
- [ ] 状态色彩区分：active / completed / dropped / attention / critical
- [ ] 显示"下一步"行动文案（如"完成 BST 学习单元"）
- [ ] 不把"硬课"或教师做成羞辱性标签

### US-03：从课程进入学习（P0-JUMP-01）
**角色：** 学生 · **优先级：** P0
**需求：** 我从课程卡片直接进入智课工坊的学习内容
**AC：**
- [ ] 点击"开始学习"按钮跳转到 `/student/watch/:publishedId`
- [ ] 如果该课程无已发布内容，显示"学习内容准备中"
- [ ] 跳转后返回赛季首页的导航路径清晰

### US-04：查看学习统计入口（P0-JUMP-02）
**角色：** 学生 · **优先级：** P0
**需求：** 我在课程详情中看到最近的学习统计
**AC：**
- [ ] 显示最近一次学习的完成度和正确率
- [ ] 点击"查看完整回放"跳转到 F-001 Replay 页
- [ ] 无学习记录时显示"尚未开始学习"

## 5. 不变量

1. 赛季中心是壳，不复制其他模块的业务数据
2. 不用单一 OVR 定义学生，不公开 GPA 天梯
3. 不把挂科、疾病或危机娱乐化
4. "毕业＝球衣退役"等隐喻只做庆祝文案，真实状态始终用清楚文字并列
5. 游戏化不制造伤害：不付费买分、不随机分配教育机会、不公开羞辱

---

## 6. P0 验收场景

### 端到端路径

1. 学生进入赛季首页 → 看到当前学期和 3-5 门课程阵容
2. 点击一门课程（数据结构与算法） → 看到课程详情和"开始学习"按钮
3. 点击"开始学习" → 跳转到智课工坊 BST 学习单元
4. 完成学习后 → 回到课程详情看到更新的 Box Score 摘要
5. 点击"查看完整回放" → 跳转到 Replay 页

### 必须覆盖的状态

- 正常路径：有课程内容、有学习记录
- 空状态：新课程无学习内容、未开始学习
- 回退路径：fixture 数据完整展示

## 9. 产品验证问题

| 假设 | 最小验证 | 不可过度声称 |
|---|---|---|
| MyCareer 外壳能让闭环更好懂 | 比较有/无外壳的首次任务理解 | 不能据此声称提高留存 |
| 赛季语法不制造焦虑 | 让学生解释含义并报告情绪 | 不能据此声称改善学习体验 |

## 10. University OS 与统一体验边界

- F-010～F-012 的通行、余额和饮食只以摘要卡与 Next Move 进入 MyCareer；正式账务、门禁和餐饮信息仍由各模块/权威系统负责。
- 教师 Coach Studio 与学校 Front Office 使用同一 Experience Shell、Design Tokens、状态词典和 Replay 语法；它们不是 F-002 的学生数据复制品。
- 沉浸、轻量、传统和减少动效模式共享同一信息架构与功能完成度，切换只改变叙事强度。
