# Performance Center · 功能规格

> **模块编号：** F-006 · **优先级：** P2  
> **基线日期：** 2026-07-22  
> **状态：** Fixture 纵向切片技术候选；等待人类接受，Degree Fahrenheit 人因结论仍为 `DEFER`
> **稳定 ID：** 沿用 2026-07-21 八入口版本；既有 ID 不得改义或复用。

## 1. 使命

给学生私密、可解释、可行动的进度与负荷反馈，而不是把人压成一个永久 OVR。每个指标都能回到来源，每个状态都有时间范围，每条建议都允许质疑、纠错和关闭。

## 4. Degree Fahrenheit 实验

`Degree Fahrenheit · Academic Climate` 只可作为本人私密、主动开启、随时关闭的短期状态语言测试，不是成绩、能力值、医学温度或科学测量。60/70°F 属于环境温度隐喻，98.6/100°F 属于人体温度隐喻，不能把四点连成“越高越好”的连续量表；第一版不得设权重或合成总分，必须与原始维度并列。完整评价因素、A/B/C 对照与访谈协议见 [人因研究章程](../../product/HUMAN-FACTORS.md#6-degree-fahrenheit-专项协议)。

| 表达 | 可测试含义 | 必须同时显示 |
|---|---|---|
| `98.6°F · 稳态` | 可测试的离散文案：接近本人近期可持续状态 | 原始维度、依据、时间范围、非医学声明 |
| `100°F · 过热` | 可测试的离散文案：短期投入过高或负荷失衡 | 减压/求助动作，不能庆祝“越高越好” |
| `70°F · 室温` | 可测试的离散文案：日常、可维持但仍有下一步 | 原始维度与下一步，不等同于 70 分 |
| `60°F · 回暖中` | 可测试的离散文案：正在恢复或重新建立节奏 | 原始维度，避免刻度方向被误读 |

采用闸门：必须将“带数字隐喻 / 只用文字状态 / 无隐喻多维面板”三版做首读认知访谈，记录原话、反例和样本局限。只要反复出现成绩、医学诊断或“越高越好”的误解，就先改版；无法消除时回退为普通文字或无隐喻多维面板，不用说明文字强行保留梗。可执行脚本、刺激材料、匿名记录模板与停止规则见 [`HF-02-DEGREE-FAHRENHEIT.md`](HF-02-DEGREE-FAHRENHEIT.md)；截至 2026-07-24 仍为 0 位参与者，因此默认且唯一可用于普通演示的是 C 版。

## 5. 不变量

1. 所有指标默认私密，跨人比较默认关闭。
2. 不公开 GPA/OVR 天梯，不生成永久能力标签，不暗示医学诊断。
3. 教师、雇主或管理员未经学生逐项同意不得查看。
4. 付费、社交热度和随机机制不能改变能力分、资格或排序。
5. 无来源、样本不足、过期或冲突的数据不显示伪精确结论。
6. 图表必须满足 F006-13，不能把可访问性留给全局口号代替模块验收。
