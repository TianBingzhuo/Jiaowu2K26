## P0 不可稀释的两部分

### F-001 智课工坊：真正的纵向切片

1. 从一份有权使用的课程材料定位来源片段；
2. 生成或构造一个符合数据合同的草稿对象；
3. 教师查看来源，修改、通过或移除；
4. 未通过的对象不得发布；
5. 学生与一个已通过对象互动，并能查看来源或复盘。

详细定义见 [SMARTCOURSE.md](SMARTCOURSE.md)。

### F-002 MyCareer 外壳：只做能帮助理解 P0 的部分

P0 可以有一个轻量赛季/课程入口，让评委理解智课工坊是 jiaowu2K26 某门课的一次“赛前准备 → 教练审核 → 球员学习 → Box Score 复盘”，但不在 P0 同时做完全部学期、全部课程和全部统计。

## P1 候选：P0 稳定后最多选一个

### 候选 A：Academic Mirror 小样导入

- 用授权样例或手工导入的课程/学期数据；
- 每条记录保存 `source_system`、`external_id`、`source_version`、`fetched_at`、`authority_level`；
- 不依赖真实校方账号、绕过登录的爬取或对校方系统写入。

### 候选 B：个人 Roster Lab

- 输入：课程偏好、已修状态、必修 pins、学分上限和时间冲突；
- 输出：候选课程阵容、与当前方案的 diff、未满足项和可重现的 `semester.lock`；
- 个人规划可评估 SAT / MaxSAT，但不在未实测前锁定库。

### 候选 C：World Exam Finals 回放层

- 将智课工坊的来源、审核、答题和复习卡组合成一次赛事回放；
- 保留“AI 参加开卷考，老师真正核对那本书”的 `Show your work` 记忆点；
- 不为了搞笑将挂科、疾病或学业危机娱乐化。

### 候选 D：Opportunity Market 透明匹配

- 用 5–10 条公开、虚构或明确授权的机会样例；
- 输出“已满足 / 可能满足 / 未满足 / 未知”及其依据，不只给综合分；
- 由学生明确选择哪些资料用于匹配以及是否表达意向；
- 不接真实招聘账号，不自动投递，不做付费排名、随机资格或给人竞价；
- 完整边界见 [OPPORTUNITY-MARKET.md](OPPORTUNITY-MARKET.md)。

## P2 / Vision 产品语法库

### 学制与赛季

- 4 个赛季 → 常见本科阶段隐喻；
- 6 个赛季 → 本科后硕士阶段或六年培养路径隐喻；
- 8 个赛季 → 博士/更长培养阶段隐喻；
- 必须允许延毕、休学、交换、专升本、联合培养等非线性路径，不把所有人锁死在 4/6/8。

### 选课与阵容

| 大学行为 | 2K 隐喻 | 产品用途 |
|---|---|---|
| 选课 | 选秀 / 自由市场 | 比较课程、名额、风险和阵容作用 |
| 加课 / 退课 / 换课 | 签约 / 裁员 / 交易 | 显示 transaction 的前后 diff |
| 学分上限 | 工资帽 | 显示学分、时间和精力预算 |
| 先修 / 并修 | 参选资格 | 解释为什么可选/不可选 |
| Waitlist | 发展联盟等待征召 | 展示队列、候补方案与变更通知 |
| 必修硬课 | 已锁定合同 | 说明不可移动原因，不将课程或教师污名化 |
| 转专业 | 申请交易 | 展示学分继承、新要求和时间影响 |
| 毕业 | 球衣退役 | 归档成果、经验与传承 |

### Performance Center 与 Degree Fahrenheit

`Degree Fahrenheit` 是一个待验证的反馈隐喻，不是真实温度或学术标准：

- `98.6°F` 可表示稳定、舒适、接近个人最佳状态；
- `100°F` 可表示“发热/爆发”，但也要提醒负荷过高；
- `70°F` 可表示室温、日常、尚可；
- `60°F` 不应被称为“春暖花开级”而不解释语境；整个尺度需要先做可理解性测试。

评分原则：不把人等同于一个 OVR，不用公开排名制造羞辱，并让用户看见指标从哪里来、能用来做什么、不能代表什么。

### Coach & Scouting

候选字段可包括考核形式、作业频率、小组作业比例、Office Hours、教材和先修建议。任何“教练风格”或“球探报告”都要优先使用教师公开说明和可验证信息，不将匿名情绪或 Rate My Professor 式评论直接变成事实。

### Opportunity Market 与权益系统

VC 只转译为不可购买的时间、精力、实验室或资助预算；卡包只保留“主题集合”，且打开前完全透明；拍卖行改成双方同意的机会匹配；Pass 只记录真实会议、数据库、Workshop、差旅和奖学金等权益。跳级、转专业和转学进入可解释的 Pathway Portal，系统不代替正式审批。
