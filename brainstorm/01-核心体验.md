# 核心体验

## 体验承诺

> 在 jiaowu2K26 中，教师把沉睡的课程资产变成可审核、可互动、可复习的学习单元；学生获得更短、更互动、更知道重点在哪里的学习体验；每一次选择都有依据，每一次进步都能回放。

[来源: 评委打分对照页.md + PRODUCT.md]

### 三种角色 Lens 的体验承诺

| 角色 Lens | 一句话体验承诺 |
|-----------|--------------|
| 学生 MyCareer | 在 jiaowu2K26 中，每一次选择都有依据，每一次进步都能回放 |
| 教师 Coach Studio | 从教学设计、课程反馈、科研机会到晋升准备，每一步都有来源和证据，系统建议但不替代专业判断 |
| 学校 Front Office | 从招生、排课、学生支持到政策 What-if，所有建议显示假设和受影响群体，学校责任人保留最终决定 |

## 产品哲学

> "把 AI 放在教研助理的位置，而不是让它直接成为授课老师。"

智课工坊不是替老师凭空生成内容，而是把老师沉睡的课程资产转成可审核、可互动、可复习的学习体验。每个脚本、题目、复习卡都能追溯到原始 PPT 和老师口播，老师审核后才发布给学生。[来源: 评委打分对照页.md]

## 十一条设计原则

以下原则从 PRODUCT.md "共同产品原则"提炼，是 jiaowu2K26 所有模块共享的产品价值观：

1. **体验层不冒充权威层**
   镜像、预测和 What-if 必须显式标注来源、版本、时效和权威等级。产品是 SIS/URP/LMS 之上的解释层，不替代正式系统。[来源: PRODUCT.md]

2. **AI 必须 Show your work**
   能回到来源、规则、版本和人的决定。每个 AI 输出（脚本、题目、复习卡）都可追溯到原始材料的页码、时间戳或文本跨度。无法支持的断言标记"证据不足"，不得编造来源。[来源: PRODUCT.md + 评委打分对照页.md]

3. **人保留决定权**
   教师决定发布，学生决定披露，学校决定正式资格。AI 生成内容只有经过教师审核（通过/修改/移除）后才能发布给学生。[来源: PRODUCT.md]

4. **2K 是产品语法，不是品牌复制**
   借鉴赛季、阵容、训练、关键事件、回放和管理循环的设计思想，不复制 NBA 2K 的品牌、画面、商标或具体布局。[来源: PRODUCT.md + RESEARCH.md]

5. **解释优先于综合分**
   先显示已知、未知、依据和下一步，再考虑汇总指标。不用单一 OVR 定义学生，不用一个百分比掩盖不确定性。[来源: PRODUCT.md]

6. **游戏化不制造伤害**
   不付费买分、不随机分配教育机会、不公开羞辱、不把人商品化。时间/精力/资源不可购买成绩资格。[来源: PRODUCT.md]

7. **小闭环先于功能展柜**
   P0 只证明"来源 → 审核 → 发布 → 互动 → 回放"这一条最短闭环。不做功能堆叠，先验证核心价值。[来源: PRODUCT.md]

8. **每项能力可回退**
   网络、模型、数据库或硬件失效时仍可诚实演示核心价值。预加载 golden 数据和 fallback 方案确保路演稳定。[来源: PRODUCT.md + 评委打分对照页.md]

9. **一个世界而非模块拼盘** — 所有角色和模块强制复用同一游戏化外壳、Token、组件、图标、动效和叙事语法；模块不得独立换肤。`[来源: VISION.md]`
10. **统一不等于强迫沉浸** — 沉浸、轻量、传统和减少动效模式共享同一信息架构与完成度，用户可降噪但不会掉进粗糙后台。`[来源: VISION.md]`
11. **真实权益不做游戏货币** — General Balance、政策资金、外部支付通道、Module Cap 和非货币 Entitlement 分层呈现，绝不付费买成绩、资格或优先级。`[来源: VISION.md]`

## NBA 2K 机制转译

从 RESEARCH.md 的 NBA 2K 机制研究中提炼，以下 26 条是快速摘要，不再声称是“全部功能”。NBA 2K25 各系统、历代版本校正、maimai DX 微交互和逐项采用/拒绝判断统一见 [03-2K全功能对标与实现构思.md](03-2K全功能对标与实现构思.md)。

### 核心跨模式循环

```text
建立身份/选择构筑 → 选择目标/阵容/资源 → 训练与低风险试错 → 参加关键事件/赛季
    → 即时反馈/回放/数据/奖励 → 调整属性/阵容/战术 → 跨赛季积累生涯/收藏/历史
```

jiaowu2K26 的对应循环：建立学习目标 → 配课程/机会 → 练习 → 关键任务 → 证据回放 → 调整路径 → 留下生涯档案。[来源: RESEARCH.md]

### 转译矩阵

| 2K 机制 | 教育转译 | 保留/修改/删除 | 理由 |
|--------|----------|----------------|------|
| **赛季模式 (Seasons)** | 学期 = 赛季，4/6/8 阶段大学生涯 | 保留 | 学期节奏天然匹配；支持非线性路径（休学、延毕、交换） |
| **阵容管理 (Lineup)** | 课程 = 阵容，课程卡显示角色/学分/状态 | 保留 | 让"当前学期在修什么"一目了然 |
| **训练系统 (Learn 2K)** | 无惩罚练习、理解检查、可重试 | 保留 | 低风险试错是学习的核心，Warm-up → Drill → Key Match 递进 |
| **Replay/Box Score** | 来源/审核/答题回放、阶段总结 | 保留 | 每次作答可回看来源、教师说明和修正，不是黑箱分数 |
| **MyCareer 生涯** | 入学到毕业的连续档案 | 保留 | 长期积累作品、徽章、选择理由，毕业后可导出不因离校清空 |
| **MyPLAYER Builder** | 培养目标、课程 What-if、资格解释 | 修改 | 借鉴并排因果展示（左约束→中属性→右资格），但拒绝单一 OVR |
| **卡片/包 (Card Pack)** | 透明机会包（按主题组织，无付费随机） | 修改 | 只借鉴主题化发现，删除付费随机、概率操纵、FOMO |
| **拍卖行 (Auction House)** | 机会市场搜索/供需/双方确认 | 修改 | 保留搜索和匹配逻辑，删除给学生/导师/岗位竞价 |
| **Play Now** | 首页只保留一个主行动（今日学习） | 保留 | 最短路径进入学习，一屏一主任务 |
| **Key Games** | 关键课程/考试/项目 | 修改 | 由学生/课程明确选择，不以算法强行制造焦虑 |
| **The City 枢纽** | Campus Hub、个人空间、服务入口 | 修改 | 借鉴集中枢纽价值，用二维 Hub 实现，不做 3D 校园 P0 |
| **Squad Finder** | 项目/竞赛组队偏好与时间 | 修改 | 显式筛选条件，敏感信息默认不用 |
| **REP/Badges** | 可解释能力/行为徽章/短期状态 | 修改 | 只奖励可观察行为和明确标准，状态而非身份，支持到期/撤回 |
| **MyNBA/MyGM** | 教师/管理员工作台与运营视角 | 修改 | 借鉴管理模拟思想，做可解释运营决策，不做全校排课 P0 |
| **VC 货币经济** | Capacity：时间/精力/实验室容量 | 修改 | 保留资源取舍的抽象，删除付费买分/能力/资格/排名 |
| **Progression 成长曲线** | 大一→大四可见解锁弧线（不用数字 OVR） | 修改 | 保留“成长的可见节奏”，拒绝单一数字定义学生 |
| **Daily/Weekly Challenges** | 可选、可静音的周任务板 | 修改 | 保留节奏与发现，删除日活强迫、FOMO、惩罚和倒计时 |
| **Co-op / Crews** | 学习小组：组队刷题、互相看 Replay | 修改 | 保留协作动力，拒绝组间排名和强制参与 |
| **Moments / Mamba Moments（2K24/系列机制）** | “重现经典考题”情境化练习 | 修改 | 保留叙事张力，拒绝羞辱式对比；不误写成 2K25 新功能 |
| **Broadcast Package** | 赛前简报 + 中场统计 + 赛后复盘 | 保留 | 完整的“赛事包装”节奏感 |
| **Hot Zones / Shot Chart** | 知识热区图（绿/黄/灰/红） | 修改 | 保留一眼看出强弱的直觉，拒绝公开和焦虑制造 |
| **Season Awards / Highlight Reel** | 学期里程碑、多元贡献奖 + 可编辑私密集锦 | 修改 | 不按 GPA 选全明星、不做人气总榜，公开完全自愿 |
| **Takeover 临场强化** | 本人主动开启的 Focus Sprint | 修改 | 只减少干扰和调整提示，不因“连胜”加分、不设中断惩罚 |
| **Player Lock 视角控制** | 聚焦模式：今天只关注一门课 | 保留 | 极低成本的体验提升 |
| **Locker Codes** | 教师解锁码→额外内容 | 修改 | 保留惊喜感，删除限量/稀缺/FOMO |
| **Draft 选秀** | 选课 = 方案板（课程事实 + 来源 + 约束 + 取舍） | 修改 | Roster Lab 的视觉包装层，不用身体或秘密画像数据 |

[来源: RESEARCH.md + PRODUCT.md + 03-2K全功能对标与实现构思.md]

### maimai 补充：微观学习节拍

maimai 不替代上述生涯系统，而用于单次学习体验：TAP/HOLD/SLIDE/TOUCH 映射选择、持续观察、排序/因果与图中定位；多谱面难度映射同一目标的不同支架；Freedom Mode 提供低压力练习；BUDDY Chart 变成真正互补的双人任务。DX Rating、付费 Ticket、断签、公开段位与品牌资产不直接迁移，详见全量对标文档。

### 不应照搬的可用性问题

从 NBA 2K 界面研究中识别出的、不应迁移到教育场景的模式：

- 过多菜单层级、货币与卡片造成认知过载
- 频繁奖励与倒计时把重要教育行为变成留存操纵
- 体育竞技的赢家/输家语境不适合成绩、健康和个人困境
- 颜色类别繁多时对色觉用户不友好
- 控制器提示不能直接移植到键鼠/触屏
- 高对比、全大写、动效在长时间学习/审核中可能疲劳

## 体验反模式（不做清单）

以下机制被明确拒绝，不进入 jiaowu2K26 的任何模块：

### 来自产品原则的拒绝

- **公开排行榜羞辱**：不公开 GPA/OVR 天梯，不公开班级排名或伪精确胜率
- **伪医学温度标签**：Degree Fahrenheit 只能是本人主动开启的界面隐喻，并列原始指标且明确非医学/非成绩；不能用于诊断、排名或权威决策
- **成瘾式付费机制**：不付费买分、不付费加速、不付费跳级、不绕过先修/审批
- **人员拍卖/卡包**：不给学生/导师/岗位竞价，不做付费随机/概率操纵/FOMO
- **永久能力标签**：不以单一人格 OVR 定义学生，不用一场失误定义长期能力
- **商品化人格**：不把人当卡片交易、不用"预测成功率"替代真实建议

[来源: PRODUCT.md]

### 来自 2K 研究的拒绝

- **黑箱综合分**：先解释已知/未知/依据，再考虑汇总
- **人为稀缺**：机会信息完全透明，不靠稀有度遮蔽
- **倒计时留存操纵**：不用 FOMO 制造焦虑，赛事语言可关闭
- **付费 Pass 绕过资格**：时间/精力/资源不可购买成绩资格
- **公开天梯**：排名私密/自愿且不决定权益

[来源: RESEARCH.md + PRODUCT.md]

### 来自智课工坊场景的拒绝

- **消除教师审核权**：AI 生成内容必须经教师审核才能发布
- **消除来源追溯**：每个输出都必须可追溯到原始材料
- **伪精确实时数据**：无样本不显示结果数字，过期数据标注时效
- **强制社交曝光**：学生控制资料披露范围，默认最小采集/最小披露

[来源: PRODUCT.md + 用户旅程分析.md]

## 关键体验场景（P0 闭环）

P0 只证明一条最短闭环：

```text
预加载课程材料 → 教师审核 → 学生播放器 → 中途题目 → 复习卡
```

**验收标准**：用一份授权材料完成"定位来源 → 生成草稿 → 教师查看来源并修改/通过/移除 → 只发布已通过对象 → 学生完成互动并回看来源"。全程有失败状态、审计事件和可演示回退。[来源: PRODUCT.md]
