# jiaowu2K26 · 2K 产品语法与体验原则（现场待设计）

> 本目录只保留设计原则和现场待办，不含成品界面、原型截图、设计稿或可运行页面。
> 完整模式清单与官方来源见 [NBA 2K 功能谱系与 jiaowu2K26 映射](../docs/research/NBA2K-FEATURE-MAP.md)。

## 总项目原则

- NBA 2K 的价值在赛季、阵容、教练、回放、数据与徽章结构，不只是深色、大字和动效；
- 游戏化必须帮助学生理解、选择和行动，不使用公开羞辱、伪精确排名或病理化隐喻制造压力；
- 统一的 MyCareer 外壳服务所有模块，但 P0 只做能说明智课工坊上下文的最小部分；
- 任何数据卡都要说明来源、更新时间、用途和局限。
- MyTEAM、VC、卡包、拍卖行与 Pass 只能转译为透明机会、不可购买的资源预算和真实权益，具体边界见 [Opportunity Market](../docs/features/OPPORTUNITY-MARKET.md)。

## 智课工坊 P0 原则

- 让“来源—生成对象—教师决策”关系一眼可见；
- 审核动作使用明确文字，不依赖模糊图标；
- 状态至少区分待审、已修改、已通过和已移除；
- 置信度不伪装成事实，优先展示来源强弱与风险；
- 学生端只显示教师批准的内容；
- 先保证演示清楚和可用，再补品牌装饰。

## 实验性语法的使用闸门

- `World Exam Finals` 首先是叙事与记忆点；只有当它能改善复习、证据回放或进度理解时才进功能。
- `Degree Fahrenheit` 是待测的视觉隐喻，不是学业测量标准；展示 `98.6°F`、`100°F` 等等级前，先测试用户能否正确理解。
- 课程/教师的 Coach Profile 优先展示公开、可验证的教学结构，不将匿名情绪直接转成事实标签。

## 正式开赛后待办

1. 根据现场实现画低保真草图；
2. 定义最小赛季/课程导航，确保评委知道智课工坊属于 jiaowu2K26；
3. 选定最小颜色、字体、间距、数据卡和反馈动效体系；
4. 完成教师审核与学生体验两个关键界面；
5. 检查键盘、对比度、减少动效、空状态和错误状态；
6. 从现场版本导出截图并标注生成时间。
