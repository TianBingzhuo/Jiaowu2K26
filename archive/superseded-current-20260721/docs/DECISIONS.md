## 当前决策

### D-001 — 唯一总项目名为 jiaowu2K26

- **状态**：已接受
- **日期**：2026-07-20
- **决策**：`jiaowu2K26` 是总项目和对外品牌；它是大学生活与学习的 NBA 2K 式 MyCareer 体验层。
- **原因**：项目已从单一课程生成工具，扩展到学期、选课、成长、考试与校园生活的统一体验。
- **影响**：文档标题不再把 `jiaowu2K26` 和 `SmartCourse Studio` 并列为两个项目。
- **来源**：用户在 2026-07-20 明确纠正项目层级。

### D-002 — 智课工坊是起点与首个 P0 模块

- **状态**：已接受
- **日期**：2026-07-20
- **决策**：“智课工坊（SmartCourse Studio）”是 jiaowu2K26 最初的产品想法，现为总项目中首个可验证的 P0 功能模块。
- **核心闭环**：课程材料 → 可定位来源 → AI 草稿 → 教师审核 → 学生互动。
- **影响**：可以用智课工坊讲 P0 Demo，但不得用它代替总项目定义。
- **详情**：[features/SMARTCOURSE.md](features/SMARTCOURSE.md)

### D-003 — 产品是体验层，不是赛内重写 SIS

- **状态**：已接受
- **日期**：2026-07-19
- **决策**：jiaowu2K26 优先作为现有 SIS / URP / LMS 之上的学生体验层和教师工作流层。
- **原因**：72 小时无法负责任地重建学籍、财务、权限、成绩入库等权威业务。
- **实现含义**：使用 `Academic Mirror` 保留外部来源、版本和权威等级，不伪装成校方权威源。

### D-004 — NBA 2K 是产品语法，不是换皮

- **状态**：已接受
- **日期**：2026-07-19
- **决策**：复用 MyCareer、赛季、阵容、教练、球探、回放、数据面板和徽章等产品结构，而不只模仿颜色、字体或动效。
- **原则**：先让学习与选择更清楚、更有反馈，再谈娱乐化；不将 GPA 排名等敏感信息做成伤害学生的竞技压力。

### D-005 — Rust-first 模块化单体

- **状态**：条件接受
- **日期**：2026-07-19
- **决策**：核心 API 候选为 Rust + Axum + Tokio 的模块化单体；不拆微服务，不要求 AI / OCR 工具全部用 Rust。
- **闸门**：开赛后 6 小时内必须跑通最小写入、查询、审核状态迁移和前端调用；否则回退到团队更熟悉的后端。
- **详情**：[tech-stacks/CORE-ARCHITECTURE.md](tech-stacks/CORE-ARCHITECTURE.md)

### D-006 — OceanBase 是有回退的条件主存储

- **状态**：条件接受
- **日期**：2026-07-19
- **决策**：仅当 OceanBase MySQL 模式 + SQLx 在现场通过连接、迁移、事务和关键查询小样时，才作为主数据层。
- **回退**：SQLite / JSONL 使用相同领域数据合同。
- **边界**：不为“分布式”标签强行上库，不将 MySQL 兼容误写为所有功能完全等同。

### D-007 — Conda 式 Semester Environment Resolver

- **状态**：已接受为 P1/P2 设计方向
- **日期**：2026-07-19
- **决策**：借鉴 Conda 的 specs、prefix、pins、dependencies、conflicts、final state、diff、transaction 和 lockfile 语义，设计“学期环境求解器”。
- **求解后端**：个人选课可候选 SAT / MaxSAT；全校课程-教师-教室排程可候选 CP-SAT / 通用约束优化；需有确定性启发式回退。
- **已拒绝的误用**：不直接把 Conda / libsolv 软件包代码硬套到全校排课。
- **优先级**：不得挤占智课工坊 P0 闭环。

### D-008 — 开源优先，但每次复用必须可审计

- **状态**：已接受
- **日期**：2026-07-20
- **决策**：优先复用成熟开源库、组件和经验，避免在 72 小时里重造通用轮子；但不因“开源”就默认可用。
- **必填信息**：上游仓库、版本/提交、许可证、复用方式、修改、依赖、已知风险、现场验证结果和归属文件。
- **详情**：[tech-stacks/OPEN-SOURCE-REUSE.md](tech-stacks/OPEN-SOURCE-REUSE.md)

### D-009 — 所有成熟结论都必须脱离对话存活

- **状态**：已接受
- **日期**：2026-07-20
- **决策**：已形成明确判断的产品、技术、数据或合规结论，必须及时归纳到项目文件，不能只保留在某个 AI 对话里。
- **同步顺序**：主题文档 → 本决策日志 → `PROJECT-MANIFEST.json` → `AI-HANDOFF.md`。
- **交接规则**：新 AI 先读 [AI-HANDOFF.md](AI-HANDOFF.md)，不以对话摘要或 `archive/` 取代当前主线。

### D-010 — 将 2K 经济系统改造成透明机会与权益系统

- **状态**：已接受为 P1/P2 产品方向
- **日期**：2026-07-21
- **决策**：VC 只表达不可购买的时间、精力、实验室或资助容量；卡包改成内容完全透明的机会包；拍卖行改成双方同意的机会匹配；Pass 只记录真实权益；Transfer Portal 只解释转段资格、影响与审批路径。
- **拒绝项**：付费买分、付费跳过先修/审批、随机分配教育机会、出售匹配优先权、给学生/导师/岗位竞价，以及未经同意共享个人档案。
- **闸门**：只有智课工坊 P0 稳定、数据来源有权使用、资格解释和同意/纠错可完整展示时，才能作为现场唯一 P1 候选之一。
- **证据与设计**：[features/OPPORTUNITY-MARKET.md](features/OPPORTUNITY-MARKET.md)、[research/NBA2K-FEATURE-MAP.md](research/NBA2K-FEATURE-MAP.md)。

### D-011 — 校方系统保持权威，集成默认只读且必须授权

- **状态**：已接受
- **日期**：2026-07-21
- **决策**：UAccess、URP、LMS、顾问/CRM 等外部系统仍是其业务的权威来源；jiaowu2K26 通过 `Academic Mirror` 提供解释和体验，默认不写回。
- **禁止**：采集学生教务密码、绕过登录/验证码抓取、把镜像或 What-if 冒充正式结果，以及在黑客松使用未经授权的生产学生数据。
- **允许路径**：学校批准的 API、授权导出、人工导入，或虚构/明确授权的演示样例；每条镜像保留来源、版本、同步时间、权威等级、同意依据与纠错路径。
- **原因**：UArizona 公开工具呈现了记录系统、LMS 与学生支持层的职责分工；中国高校公开警示也明确暴露了第三方账号工具的安全与事实一致性风险。
- **证据**：[research/SIS-URP-UARIZONA.md](research/SIS-URP-UARIZONA.md)。
