# Fallback 素材说明

这里放录屏、截图和其他现场保底素材。

## 必备文件

- `demo_video_90s.mp4`：路演可直接播放的 90 秒版本。
- `demo_video_full.mp4`：展台或 Q&A 使用的 3 分钟版本。
- `screenshots/01_teacher_upload.png`
- `screenshots/02_script_review.png`
- `screenshots/03_student_player.png`
- `screenshots/04_quiz_overlay.png`
- `screenshots/05_code_playground.png`

## 录屏要求

- 不出现浏览器控制台。
- 不出现真实个人信息。
- 不出现未完成或报错状态。
- 本地和云端各保留一份。
