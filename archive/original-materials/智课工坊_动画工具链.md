**文档定位**：动画创作、渲染、资产管理、视频分发的全链路工具指南  
**适用阶段**：黑客松 MVP → 孵化期  
**版本**：v1.0 | 2026-06-24  
**关联文档**：《演进路线》第十一节（UI/动画实战指南）、《AI实现指南》

## 一、动画管线总览

智课工坊的动画不是"做一段动画视频"，而是**构建一套数据驱动的动画渲染管线**：LLM 生成结构化脚本 JSON → 前端根据 JSON 实时组装场景 → 输出可在浏览器播放的互动动画。整条管线分为六层：

```
┌─────────────────────────────────────────────────────┐
│ 1. 资产创作层   角色/背景/道具/图标的原始素材制作         │
│ 2. 动画编排层   将静态资产变成可驱动的动画（Lottie/Rive） │
│ 3. 场景合成层   根据脚本 JSON 组装角色+背景+文字+动画     │
│ 4. 互动增强层   出题弹层/分支选择/代码编辑器/知识炼金     │
│ 5. 播放控制层   时间轴/进度条/音画同步/TTS 对齐           │
│ 6. 分发输出层   高光切片/短视频导出/社交分享卡片           │
└─────────────────────────────────────────────────────┘
```

下面逐层展开工具链。

**孵化期推荐路径**：用 Rive 设计 2-3 套品牌角色（教师/学生/NPC），利用 Rive 的状态机实现表情切换（开心/思考/惊讶/讲解），导出为 .riv 文件后用 rive-react 播放器嵌入。

### 2.2 角色动画清单（MVP 必需）

每个角色至少需要以下动画状态，前端根据脚本 JSON 的 `animation.action` 字段切换：

| 动画名称 | 触发场景 | 时长 | 循环 |
|---------|---------|------|------|
| `idle` | 默认站立/等待 | 2s | 是 |
| `wave` | 开场打招呼 | 1.5s | 否 |
| `explain` | 讲解概念（手指/比划） | 3s | 是 |
| `think` | 抛出问题/思考 | 2s | 是 |
| `point` | 指向图表/公式 | 2s | 否 |
| `celebrate` | 学生答对时 | 1.5s | 否 |
| `shake_head` | 学生答错时 | 1s | 否 |
| `write` | 在"黑板"上书写 | 3s | 是 |
| `transition` | 场景切换过渡 | 0.8s | 否 |

LottieFiles 搜索关键词推荐：`teacher`, `presenter`, `explainer`, `character talking`, `character thinking`, `character pointing`, `celebration`, `whiteboard`。

### 3.2 Rive 工作流（孵化期升级）

Rive 相比 Lottie 的核心优势是**状态机**——可以用代码控制角色在不同状态间切换，而不需要多段独立动画。

```
状态机示例：
  idle ──(explain触发)──→ explaining
    ↑                         │
    │                    (think触发)
    │                         ▼
    └────────────────── thinking ──(celebrate触发)──→ celebrating
                                                         │
                                                    (回到idle)
```

```bash
npm install @rive-app/react-canvas  # React Rive 播放器
```

```tsx
import { useRive, useStateMachineInput } from '@rive-app/react-canvas'

function CharacterAnimation({ action }: { action: string }) {
  const { rive, RiveComponent } = useRive({
    src: '/rive/teacher.riv',
    stateMachines: 'Teacher States',
    autoplay: true,
  })
  
  const isExplaining = useStateMachineInput(rive, 'Teacher States', 'isExplaining')
  const isThinking = useStateMachineInput(rive, 'Teacher States', 'isThinking')
  const isCelebrating = useStateMachineInput(rive, 'Teacher States', 'isCelebrating')
  
  // 根据脚本 JSON 的 action 字段驱动状态
  useEffect(() => {
    if (isExplaining) isExplaining.value = (action === 'explain')
    if (isThinking) isThinking.value = (action === 'think')
    if (isCelebrating) isCelebrating.value = (action === 'celebrate')
  }, [action])
  
  return <RiveComponent className="w-32 h-32" />
}
```

### 3.3 Framer Motion 微交互动画清单

Framer Motion 负责场景中**非角色**元素的动画：文字进出场、图表构建、公式渐入、页面过渡等。

| 动画类型 | Framer Motion 特性 | 使用场景 |
|---------|-------------------|---------|
| 文字逐字/逐行出现 | `staggerChildren` + `opacity` | 旁白字幕、知识点标题 |
| 公式/代码块渐入 | `AnimatePresence` + `fadeInUp` | 数学公式、代码示例 |
| 图表柱状图生长 | `scaleY` from 0 to 1 | 数据可视化讲解 |
| 对比分屏滑入 | `type: "spring"` + `x` offset | A/B 对比讲解 |
| 场景切换过渡 | `pageTransition` variants | 两个 scene 之间 |
| 出题弹层弹出 | `scale` + `backdropFilter` | quiz overlay |
| 知识炼金效果 | `keyframes` + particle effect | 答题正确时 |
| 进度条填充 | `width` animation | 播放进度 |
| 分支选择卡片 | `layout` + `hover` scale | 学生投票 |

**Framer Motion 变体模板**（直接复制到项目中使用）：

```tsx
// lib/animations.ts — 智课工坊标准动画变体

// 场景过渡
export const sceneTransition = {
  initial: { opacity: 0, y: 20 },
  animate: { opacity: 1, y: 0 },
  exit: { opacity: 0, y: -20 },
  transition: { duration: 0.5, ease: [0.25, 0.46, 0.45, 0.94] }
}

// 文字逐行出现（stagger）
export const textContainer = {
  animate: { transition: { staggerChildren: 0.15 } }
}
export const textLine = {
  initial: { opacity: 0, y: 10 },
  animate: { opacity: 1, y: 0, transition: { duration: 0.4 } }
}

// 公式/代码块渐入
export const fadeInUp = {
  initial: { opacity: 0, y: 30, scale: 0.95 },
  animate: { opacity: 1, y: 0, scale: 1 },
  transition: { type: "spring", stiffness: 100, damping: 15 }
}

// 出题弹层（从中心弹出）
export const quizOverlay = {
  initial: { opacity: 0, scale: 0.8 },
  animate: { opacity: 1, scale: 1 },
  exit: { opacity: 0, scale: 0.9 },
  transition: { type: "spring", stiffness: 300, damping: 25 }
}

// 分支选择卡片（hover 放大）
export const branchCard = {
  rest: { scale: 1 },
  hover: { scale: 1.03, transition: { type: "spring", stiffness: 400 } },
  selected: { scale: 1.05, borderColor: "#2563EB" }
}

// 知识炼金效果（答题正确时的粒子扩散）
export const alchemyParticle = (index: number) => ({
  initial: { opacity: 1, scale: 0, x: 0, y: 0 },
  animate: {
    opacity: [1, 1, 0],
    scale: [0, 1.5, 0],
    x: Math.cos(index * 0.5) * 80,
    y: Math.sin(index * 0.5) * 80 - 40,
  },
  transition: { duration: 1.2, ease: "easeOut" }
})
```

## 四、场景合成层

场景合成是动画管线的核心——根据 LLM 生成的脚本 JSON，在浏览器中实时组装出完整的动画场景。

### 4.1 场景数据结构

```typescript
// 一个完整场景的运行时数据结构
interface RuntimeScene {
  scene_id: number
  timestamp: number        // 开始时间（秒）
  duration: number         // 持续时间（秒）
  
  // 角色层
  character: {
    name: string           // "teacher" | "student" | "npc"
    animation: string      // "explain" | "think" | "celebrate" 等
    position: "left" | "center" | "right"
    size: "sm" | "md" | "lg"
  }
  
  // 背景层
  background: {
    type: "solid" | "gradient" | "image" | "svg_pattern"
    value: string          // 颜色值/图片URL/SVG路径
    theme?: string         // 学科主题包名
  }
  
  // 内容层（可叠加多个元素）
  content: Array<{
    type: "text" | "formula" | "code" | "diagram" | "table" | "image" | "chart"
    content: string        // 文本/LaTeX/代码/图片URL
    position: "center" | "top" | "bottom" | "left" | "right"
    animation: "fade_in" | "slide_up" | "typewriter" | "build_step"
    delay: number          // 相对于场景开始的延迟（秒）
    duration?: number      // 元素自身的动画时长
  }>
  
  // 旁白层
  narration: {
    text: string           // 字幕文本
    audio_scene_id: number // 对应的 TTS 音频片段 ID
  }
  
  // 互动层（可选）
  interaction?: {
    type: "quiz" | "branch_vote" | "code_challenge" | "fill_blank"
    trigger_at: number     // 在场景内第几秒触发
    data: any              // 题目/分支/代码挑战的数据
  }
}
```

### 4.2 场景渲染器组件

```tsx
// components/player/scene-renderer.tsx
"use client"
import { motion, AnimatePresence } from "framer-motion"
import Lottie from "lottie-react"
import { sceneTransition, textContainer, textLine, fadeInUp } from "@/lib/animations"

export function SceneRenderer({ scene, currentTime }: { scene: RuntimeScene; currentTime: number }) {
  const elapsed = currentTime - scene.timestamp
  const progress = elapsed / scene.duration
  
  return (
    <motion.div
      key={scene.scene_id}
      className="absolute inset-0 overflow-hidden"
      {...sceneTransition}
    >
      {/* 背景层 */}
      <BackgroundLayer bg={scene.background} />
      
      {/* 角色层 */}
      <div className={`absolute ${characterPositionClass(scene.character.position)} bottom-4`}>
        <Lottie
          animationData={loadLottieAnimation(scene.character.name, scene.character.animation)}
          loop={shouldLoop(scene.character.animation)}
          className={`${characterSizeClass(scene.character.size)}`}
        />
      </div>
      
      {/* 内容层 */}
      <motion.div
        className="absolute inset-0 flex items-center justify-center p-12 pointer-events-none"
        variants={textContainer}
        initial="initial"
        animate="animate"
      >
        {scene.content.map((el, idx) => (
          <ContentElement key={idx} element={el} elapsed={elapsed} />
        ))}
      </motion.div>
      
      {/* 旁白字幕 */}
      <div className="absolute bottom-0 left-0 right-0 bg-gradient-to-t from-black/70 to-transparent px-8 py-5">
        <motion.p
          className="text-white text-lg text-center font-medium"
          initial={{ opacity: 0, y: 10 }}
          animate={{ opacity: 1, y: 0 }}
          transition={{ delay: 0.3 }}
        >
          {scene.narration.text}
        </motion.p>
      </div>
      
      {/* 互动层 */}
      {scene.interaction && elapsed >= scene.interaction.trigger_at && (
        <InteractionLayer interaction={scene.interaction} />
      )}
    </motion.div>
  )
}
```

### 4.3 分支选择 UI（借鉴 Volitus 共创机制）

```tsx
// components/player/branch-vote.tsx — 学生投票选择教学路径
"use client"
import { useState } from "react"
import { motion } from "framer-motion"
import { branchCard } from "@/lib/animations"

interface BranchOption {
  id: string
  title: string
  description: string
  icon: string
}

export function BranchVote({
  options,
  onVote,
  timerSeconds = 10
}: {
  options: BranchOption[]
  onVote: (optionId: string) => void
  timerSeconds?: number
}) {
  const [selected, setSelected] = useState<string | null>(null)
  const [timeLeft, setTimeLeft] = useState(timerSeconds)
  
  return (
    <motion.div
      className="absolute inset-0 bg-black/60 backdrop-blur-sm flex flex-col items-center justify-center z-50"
      initial={{ opacity: 0 }}
      animate={{ opacity: 1 }}
    >
      <h3 className="text-white text-xl font-bold mb-2">选择学习路径</h3>
      <p className="text-slate-300 text-sm mb-6">
        {timeLeft > 0 ? `${timeLeft}秒后自动选择` : "正在统计..."}
      </p>
      
      <div className="flex gap-4">
        {options.map((opt) => (
          <motion.button
            key={opt.id}
            className={`
              bg-slate-800/80 border-2 rounded-xl p-6 w-48 text-left
              transition-colors
              ${selected === opt.id ? "border-cyan-400" : "border-slate-600 hover:border-slate-400"}
            `}
            variants={branchCard}
            initial="rest"
            animate="rest"
            whileHover="hover"
            onClick={() => {
              setSelected(opt.id)
              onVote(opt.id)
            }}
          >
            <span className="text-2xl mb-2 block">{opt.icon}</span>
            <span className="text-white font-semibold block">{opt.title}</span>
            <span className="text-slate-400 text-sm">{opt.description}</span>
          </motion.button>
        ))}
      </div>
      
      {/* 投票进度条（多人投票时显示其他人选择分布） */}
      {selected && (
        <motion.div
          className="mt-6 flex gap-2"
          initial={{ opacity: 0 }}
          animate={{ opacity: 1 }}
        >
          {options.map(opt => (
            <div key={opt.id} className="text-center">
              <div className="h-2 bg-slate-700 rounded-full w-24 overflow-hidden">
                <motion.div
                  className="h-full bg-cyan-400"
                  initial={{ width: 0 }}
                  animate={{ width: `${Math.random() * 60 + 20}%` }} // Demo用随机，实际接后端
                  transition={{ duration: 1 }}
                />
              </div>
            </div>
          ))}
        </motion.div>
      )}
    </motion.div>
  )
}
```

## 五、互动增强层

### 5.1 出题弹层设计

出题弹层是智课工坊的核心差异化功能。设计原则：不中断沉浸感，覆盖在动画上方而非跳转新页面。

```
布局结构：
```

## 六、播放控制层

### 6.1 音画同步方案

智课工坊的播放器需要同时协调四个时间轴：

```
时间轴 1: TTS 音频播放（主时钟）
时间轴 2: 场景切换（根据 scene.timestamp 触发）
时间轴 3: 字幕显示（跟随当前场景 narration）
时间轴 4: 出题触发（根据 quiz.trigger_timestamp）
```

**同步策略**：以 `<audio>` 元素的 `currentTime` 为唯一时钟源，通过 `timeupdate` 事件驱动所有其他组件的状态更新。避免使用 `setInterval` 或独立的动画时钟。

### 6.2 TTS 与场景对齐

```python
# 后端：生成 TTS 时记录每段音频的实际时长，回写到脚本 JSON
# 这样可以确保场景 duration 与 TTS 音频精确匹配

async def align_tts_with_scenes(scenes: list[dict], output_dir: str) -> list[dict]:
    """为每个场景生成 TTS 并回写 duration"""
    aligned_scenes = []
    cumulative_time = 0
    
    for scene in scenes:
        audio_path = f"{output_dir}/scene_{scene['scene_id']}.mp3"
        await tts_service.generate(scene["narration"], audio_path)
        actual_duration = get_audio_duration(audio_path)
        
        # 回写：场景的 timestamp 和 duration 以 TTS 实际时长为准
        scene["timestamp"] = cumulative_time
        scene["duration"] = actual_duration
        cumulative_time += actual_duration
        
        aligned_scenes.append(scene)
    
    return aligned_scenes
```

### 9.1 性能预算

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 单个 Lottie 文件 | < 100KB | 超过则压缩或简化 |

### 9.2 Lottie 预加载策略

```tsx
// hooks/use-lottie-preload.ts
import { useEffect, useState } from 'react'

const lottieCache = new Map<string, any>()

export function useLottiePreload(url: string) {
  const [data, setData] = useState<any>(null)
  
  useEffect(() => {
    if (lottieCache.has(url)) {
      setData(lottieCache.get(url))
      return
    }
    
    fetch(url)
      .then(r => r.json())
      .then(json => {
        lottieCache.set(url, json)
        setData(json)
      })
  }, [url])
  
  return data
}
```

### 9.3 动画降级策略

当设备性能不足或 Lottie 加载失败时，降级为 CSS 动画：

```tsx
function CharacterWithFallback({ animation, fallbackEmoji }: Props) {
  const [hasError, setHasError] = useState(false)
  const animData = useLottiePreload(`/lottie/${animation}.json`)
  
  if (hasError || !animData) {
    // 降级为 emoji + CSS 动画
    return (
      <motion.div
        className="text-6xl"
        animate={{ 
          rotate: [0, -5, 5, 0],
          scale: [1, 1.05, 1]
        }}
        transition={{ repeat: Infinity, duration: 2 }}
      >
        {fallbackEmoji || "👨‍🏫"}
      </motion.div>
    )
  }
  
  return (
    <Lottie 
      animationData={animData} 
      onError={() => setHasError(true)}
      className="w-32 h-32"
    />
  )
}
```
