- [ ] 每位成员确认能解释、调试和修改自己负责的实现
- [ ] 联系方式和可投入时段已登记

### 赛事

- [ ] AdventureX 2026 官方终极指南已保存（主题/赛道/赞助权益）
- [ ] 开幕式时间（07-22 19:00-22:30）已确认
- [ ] 提交截止时间（07-26 01:00）已标记
- [ ] 理解提交字段要求：名称、描述、封面、GitHub Tag、小红书、赛道文书

### 技术准备

- [ ] 技术栈候选已排序（Primary / Secondary / Fallback）
- [ ] 本机开发环境盘点完成（OS、GPU、内存、已安装工具链）
- [ ] 授权样例材料已准备（用于 Demo 的课程 PPT / 讲义 / 音频）
- [ ] 样例材料来源、权利、版本已登记
- [ ] 已阅读 [TECH-STACK.md](../engineering/TECH-STACK.md) 技术闸门标准
- [ ] 任一队员在项目根目录问“我现在能干什么？”时，AI 能按 [AGENTS.md](../AGENTS.md) 返回一个合法赛前任务，且不会自动认领或开始构建

### 合规

- [ ] 理解"赛前不构建"边界：正式开赛后创建全新代码仓库与空白基线
- [ ] 理解 AI 使用边界：AI 可辅助部分编码，但不能让全部代码均由 AI 生成
- [ ] 理解 IP 边界：借机制不借品牌，无 NBA/2K 商标或受保护资产
- [ ] 理解证据边界：没有现场实现与证据的能力只能写"计划/愿景/候选"
- [ ] 赛前材料、历史原型和供应商样例不是本届成果，已明确区分
- [ ] University OS 扩展包（F-010～F-014）：赛前仅保留规格，不接真实支付/门禁/人事系统，不做学校试点

## P0 闭环定义（全员必读）

智课工坊 P0 主路径：

1. 教师上传课程材料（音频/PPT/讲义）
2. AI 生成结构化教学草稿（脚本/题目/复习卡），**必须亮出来源**
3. 教师审核：修改 / 通过 / 移除，**审核后才能发布**
4. 学生端播放已发布的互动内容
5. 学生完成理解检查，查看 Replay / Box Score
6. 每个结果能追溯到来源与教师修改

> **一句话**：Show your work. For AI. In education.
