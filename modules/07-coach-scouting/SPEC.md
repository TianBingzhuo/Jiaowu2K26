# Coach & Scouting · 功能规格

> **模块编号：** F-007 · **优先级：** P2  
> **基线日期：** 2026-07-22  
> **状态：** 待验证规格，不是完成声明  
> **稳定 ID：** 沿用 2026-07-21 八入口版本；既有 ID 不得改义或复用。

## 1. 使命

把课程结构、学习预期、教师公开信息、Office Hours 和组队要求做成中性、可核验的选择支持，而不是未经验证的教师人气榜或人格标签。

## 2. 功能清单

| ID | 功能 | 具体行为与验收口径 | 阶段 |
|---|---|---|---|
| F007-01 | 课程 Profile | 展示官方简介、目标、考核构成、教材、先修和更新时间 | P2 |
| F007-02 | 教学结构 | 说明讲授/讨论/实验/项目、作业频率、反馈方式和小组占比；来源可见 | P2 |
| F007-03 | Office Hours | 展示时间、地点/链接、预约方式、适用问题和无障碍信息 | P2 |
| F007-04 | 工作量区间 | 以教师说明、课程设计和自愿汇总给出区间与样本，不伪装精确承诺 | P2 |
| F007-05 | Scouting Report | 按“适合的准备 / 可能挑战 / 建议动作 / 未知”呈现，而非给教师下人格结论 | P2 |
| F007-06 | 来源徽章 | 区分教师确认、官方大纲、历史版本、学生自愿反馈和系统推断 | P2 |

| F007-14 | 报告与治理 | 提供骚扰、失实、隐私和歧视举报；严重内容先下线后复核 | P2 |

## 3. 最小数据合同

| 对象 | 最低字段 |
|---|---|
| `CourseProfile` | 课程、开课学期、教师、官方字段、版本、更新时间、`source_ids` |
| `TeachingStructure` | 活动类型、比例/频率、反馈方式、来源层级、有效学期 |
| `EvidenceBadge` | 来源类型、确认人、版本、时间、是否过期 |
| `FeedbackAggregate` | 结构化维度、样本量、时间范围、聚合规则、举报状态 |
| `TeamNeed` | 角色缺口、技能、时间、沟通方式、披露范围、匹配理由 |
| `GovernanceCase` | 举报类型、对象、证据、临时措施、复核状态、处理时限 |

教师与课程必须分开建模；课程历史版本、当前开课和教师任教关系也必须分别保存。

## 4. 不变量

1. 不复制 Rate My Professor 式未经验证的情绪排名。
2. 不把“闭卷考试、随机点名”等玩笑直接写成教师事实。
3. 学生反馈与教师确认、官方大纲、历史版本、系统推断不能混成同一可信度。
4. 工作量只显示区间、样本量和时间范围，不承诺个人必然体验。
5. 组队筛选默认不用敏感身份，也不能永久排除“能力不足者”。
6. 推荐与匹配必须能说明理由、接受纠错并通过公平审计。

## 5. 验收标准

- [ ] Profile 每个关键字段均显示来源层级、版本和更新时间。
- [ ] Scouting Report 使用“准备/挑战/建议/未知”结构，不评价人格。
- [ ] 版本对比不会把旧教师或旧课程反馈自动沿用到新开课。
- [ ] 学生反馈达到明确最小样本后才聚合公开。
- [ ] 教师可纠错并查看修订状态，历史版本可追溯。
- [ ] 组队资料由学生逐项选择披露，匹配理由可见。
- [ ] Advisor Handoff 只传递学生同意的问题和证据，不伪造导师回复。
- [ ] 公平审计覆盖敏感属性与可能的代理变量。
- [ ] 严重失实、骚扰、隐私或歧视内容可先下线，并在时限内人工复核。
- [ ] 数据不足、过期或服务不可用时显示诚实状态。
